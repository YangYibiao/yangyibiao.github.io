### 二、计算机如何工作（约 20 分钟，原"语言"与"计算机"两部分互换）

目标：先认识这台机器——从"计算机 vs 计算器"的互动切入，再落到 输入 → 处理 → 存储 → 输出 的直观模型（IPO）。

讲授内容：
0. 思考互动（问题1，「思考: 问题1」页）："计算机和计算器有什么区别？"互动链：① 表面答案——计算器只会算数，计算机什么都能干（轻松建立参与感）；② 追问"为什么"——计算器的功能固化在硬件里，计算机的功能由程序决定，装什么程序就做什么事；③ 用「问题1 的答案: 为什么计算机什么都能做？」页回收——三大区别：存储（内存外存 vs 暂存几个数）、可编程（功能固化 vs 装什么程序做什么事）、处理的信息（文本/图像/声音/视频 vs 只会数值）；④ 点睛——通用机器 vs 专用机器：打开计算器 App 就能当计算器，反过来不行，本质区别是**可编程性**；彩蛋：计算器本身也是一台小计算机，只是程序被固定了，区别不在"有没有芯片"而在"程序能不能换"；⑤ 落地——所以这门课学的是"怎么给万能机器写指令"。注意：学生若答"计算机更大、能上网"等硬件规格，用一句"为什么"拽回。
1. 「什么是计算机」页（从语言部分移入）：程序跑在哪——计算机；硬件（输入/输出/存储/CPU/内存/主板）+ 软件（操作系统/应用程序）。
2. 「计算机如何工作」页：输入 → 处理 → 存储 → 输出 → 控制 五环节；落点——==编程==就是用编程语言写指令，控制计算机执行上述任务。这一句直接引出下一部分"怎么跟机器说话"。
3. 板书关键词：可编程 → IPO

### 三、程序设计语言 + 算法思维（约 25 分钟，原"语言 22 分钟"与"计算机 15 分钟"内容重排）

目标：回答"怎么跟机器说话"——为什么需要语言、什么是程序设计语言，再用"找最高分"建立算法与编程思维。

讲授内容：
0. 「为什么需要高级语言」页（承接上一部分结尾"编程 = 写指令"）：计算机只懂 0/1 机器指令 → 机器语言（难记易错、依赖机器，表格三行是同一个 12-5 计算）→ 汇编语言（助记符、仍绑定机器）→ 高级语言（接近自然语言和数学、与机器无关、需要编译器翻译）；点出 C 是"离硬件最近的高级语言"。此页回答"为什么不能直接用 0/1 写程序"。
1. 「什么是程序设计语言」页：自然语言 vs 程序语言：自然语言灵活但有歧义（"南京市长江大桥"断句）；程序语言严格、无歧义，让机器可以准确执行。
2. 「程序能做什么」页："程序是计算机的灵魂，那程序能做什么？"——排序成绩、游戏/微信/自动驾驶。
3. 思考互动（问题2，「思考: 问题2」页）："给全班 100 个同学的成绩，怎么让计算机找出最高分？"（学生答"一眼就看到"→ 追问"计算机怎么看"→ 用课件「算法: 找最高分」页回收：假设第一个最高 → 逐个比较 → 遇到更大就替换；引出"程序 = 算法 + 数据"）
4. 找最高分例子（紧接算法页，配合课件「计算机如何工作: 找最高分」页）：把算法的每一步映射到 IPO——输入（逐个读入成绩）→ 处理（比较、更大就替换）→ 存储（记住当前最高分）→ 输出（打印最高分）。
5. 破冰小游戏（3 分钟）：一名学生扮演"计算机"，另一名先用自然语言指挥"从讲台走到门口"，再换成精确指令（"向前走3步，向右转90度，再走10步"）。体会：程序 = 精确的指令集。
6. 翻到「编程思维」页：回头用"找最高分"归纳写程序的三组要素——结构（顺序、判断、循环）、数据（存储/变量）、设计（分解）。收束："接下来要学的，就是把这些要素用 C 语言写出来"。
7. 「程序需要什么: 本课程地图」页：从 IPO 反推每个编程元素的需求来源——记住数据→变量（第2周）、计算→表达式（第3周）、不同情况→判断（第4周）、重复→循环（第5周）、复用→函数（第6-7周）、一批数据→数组（第8-9周）、字符串与内存→指针（第10-11周）、复杂组织→结构体/链表（第12-13周）、长期保存→文件（第14周）。一句话收束："每一项都是因为需要, 所以才有"——这是全学期路线图, 直接回答"为什么学这些"。
8. 板书关键词：沟通 → 精确 → 执行

## 附录：三步走代码（供课堂演示）

第一步：经典的 Hello World——认识结构和输出

```C
#include <stdio.h> // 引入标准输入输出库

// main函数，每个C程序的入口
int main() {
    // 输出信息到屏幕
    printf("Hello, World!\n"); // \n 表示换行
    return 0; // 程序正常结束
}
```

第二步：加入变量和输入——让程序"活"起来

```C
#include <stdio.h>

int main() {
    // 1. 声明变量（在内存中开辟了一个叫 age 的小盒子，用来存整数）
    int age;

    // 2. 输入 (Input)
    printf("请输入你的年龄: ");
    scanf("%d", &age); // & 表示"把输入的值存到 age 这个盒子里"

    // 3. 处理和输出 (Processing & Output)
    printf("原来你已经%d岁了呀！\n", age); // %d 是一个坑，会用 age 的值来填充这个坑
    printf("恭喜你，明年你就%d岁啦！\n", age + 1); // 这里进行了简单的计算（处理）

    return 0;
}
```

第三步：加入简单逻辑（分支）——让程序会"思考"

```C
#include <stdio.h>

int main() {
    int number;

    printf("请输入一个整数，我来判断它是奇数还是偶数: ");
    scanf("%d", &number);

    // 处理与输出 (核心：条件判断)
    if (number % 2 == 0) { // % 是求余数运算符
        printf("数字 %d 是偶数。\n", number);
    } else {
        printf("数字 %d 是奇数。\n", number);
    }

    return 0;
}
```

综合小案例：简易成绩评级器（选做）

```C
#include <stdio.h>

int main() {
  float score; // 使用浮点数类型来存储可能带小数的分数

  printf("请输入你的成绩 (0-100): ");
  scanf("%f", &score); // %f 对应浮点数

  // 输入检查（简单的逻辑）
  if (score < 0 || score > 100) {
    printf("错误！成绩必须在0到100之间。\n");
    return 1; // 非0返回通常表示程序异常结束
  }

  printf("你的成绩是: %.1f\n", score);

  // 多分支判断：真正的"处理"核心
  if (score >= 90) {
    printf("评级: 优秀！\n");
  } else if (score >= 70) {
    printf("评级: 良好。\n");
  } else if (score >= 60) {
    printf("评级: 及格。\n");
  } else {
    printf("评级: 不及格，要加油了！\n");
  }

  return 0;
}
```
