##### 序列容器：`vector` / `list` / `deque`

---

<div class="table-sm">

| 容器 | 底层结构 | 随机访问 | 中间插入/删除 | 尾部插入 | 典型场景 |
| :-- | :-- | :--: | :--: | :--: | :-- |
| `vector` | 动态数组 | O(1) | O(n) | 均摊 O(1) | 默认选择、频繁遍历 |
| `list` | 双向链表 | 不支持 | O(1) | O(1) | 频繁任意位置插入删除 |
| `deque` | 分段连续空间 | O(1) | O(n) | O(1) | 两端频繁增删 |

</div>

<div class="cols mt1">

<div class="col">

```cpp
std::vector<int> v{3, 1, 2};
v.push_back(4);
std::sort(v.begin(), v.end());
```

</div>

<div class="col">

```cpp
std::list<int> l{3, 1, 2};
l.push_front(0);
l.remove(1);   // 按值删除
```

</div>

</div>

<div class="tip">
<span class="label">默认选择</span>
没有特殊理由时用 <code>std::vector</code>：缓存友好、随机访问快、内存连续。只有确实需要频繁中间插入/删除时才考虑 <code>list</code>。
</div>

##### 关联容器：`map` / `set` / `unordered_*`

---

<div class="cols">

<div class="col-55">

```cpp
std::map<int, Task> by_id;
by_id.emplace(1, Task(1, "写作业", 2));
by_id[2] = Task(2, "复习", 4);

if (auto it = by_id.find(1); it != by_id.end()) {
    std::cout << it->second;
}

std::set<int> ids{3, 1, 2};   // 有序、去重
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">选择</div>

- `map` / `set`：有序，查找 O(log n)，基于平衡树
- `unordered_map` / `unordered_set`：哈希，平均 O(1)，无序
- `multimap` / `multiset`：允许重复关键字

</div>

<div class="pitfall">
<span class="label">注意</span>
<code>map::operator[]</code> 在键不存在时会<strong>插入</strong>一个默认值；只查询时用 <code>find</code> 或 <code>at</code>。
</div>

</div>

</div>

##### 容器适配器：`stack` / `queue` / `priority_queue`

---

<div class="table-sm">

| 适配器 | 操作 | 底层默认 | 典型场景 |
| :-- | :-- | :-- | :-- |
| `stack<T>` | `push` / `pop` / `top` | `deque<T>` | 后进先出 |
| `queue<T>` | `push` / `pop` / `front` | `deque<T>` | 先进先出 |
| `priority_queue<T>` | `push` / `pop` / `top` | `vector<T>` + 堆 | 优先级调度 |

</div>

<div class="cols mt1">

<div class="col">

```cpp
std::stack<int> s;
s.push(1);
s.push(2);
int x = s.top();   // 2
s.pop();
```

</div>

<div class="col">

```cpp
std::priority_queue<Task> pq;
pq.push(Task(1, "低", 1));
pq.push(Task(2, "高", 5));
Task top = pq.top();   // 优先级最高
```

</div>

</div>

<div class="keypoint">
<span class="label">要求</span>
<code>priority_queue&lt;Task&gt;</code> 需要 <code>Task</code> 支持 <code>operator&lt;</code>；默认是<strong>最大堆</strong>（top 为最大元素）。
</div>

##### 迭代器：抽象的指针

---

<div class="cols">

<div class="col-55">

```cpp
std::vector<int> v{10, 20, 30};

for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << ' ';
}

auto it = std::find(v.begin(), v.end(), 20);
if (it != v.end()) {
    std::cout << "found at "
              << std::distance(v.begin(), it);
}
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">五类迭代器</div>

- 输入 / 输出
- 前向
- 双向
- 随机访问

`vector`、`deque` 提供随机访问；`list`、`map`、`set` 提供双向；`stack`、`queue` 不提供迭代器。

</div>

<div class="small muted mt1">
算法要求的迭代器类别写在模板参数名里（如 <code>RanIt</code>、<code>BidIt</code>）；传入不满足的迭代器会编译失败。
</div>

</div>

</div>

##### 范围 `for` 与 `auto`

---

<div class="cols">

<div class="col-55">

```cpp
std::vector<Task> tasks;

for (const Task& t : tasks) {   // 只读，不拷贝
    std::cout << t;
}

for (Task& t : tasks) {         // 可修改
    t.complete();
}

for (auto& t : tasks) {         // 类型由编译器推导
    t.postpone();
}
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">等价写法</div>

```cpp
for (auto it = tasks.begin();
     it != tasks.end(); ++it) {
    const Task& t = *it;
    // ...
}
```

范围 `for` 只是语法糖；底层仍然是迭代器。

</div>

<div class="tip">
<span class="label">选择</span>
只读用 <code>const auto&amp;</code>；需要修改用 <code>auto&amp;</code>；只有在确实需要副本时才按值。
</div>

</div>

</div>

##### 常用算法：查找、排序、统计

---

<div class="cols">

<div class="col-55 code-sm">

```cpp
#include <algorithm>
#include <numeric>

std::vector<int> v{5, 1, 4, 2, 3};

std::sort(v.begin(), v.end());          // 1 2 3 4 5
bool has3 = std::binary_search(
    v.begin(), v.end(), 3);

auto it = std::find(v.begin(), v.end(), 4);
int n = std::count_if(
    v.begin(), v.end(),
    [](int x) { return x % 2 == 0; });  // 2
int sum = std::accumulate(
    v.begin(), v.end(), 0);             // 15
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">算法族</div>

- 查找：`find`、`find_if`、`binary_search`
- 排序：`sort`、`stable_sort`、`partial_sort`
- 统计：`count`、`count_if`、`accumulate`
- 变换：`transform`、`copy`、`copy_if`
- 删除：`remove_if` + `erase`

</div>

<div class="small muted mt1">
算法接收<strong>迭代器区间</strong> <code>[first, last)</code>，不接收容器本身；因此同一个算法能服务多种容器。
</div>

</div>

</div>

##### Lambda：匿名函数与捕获

---

<div class="cols">

<div class="col-55 code-sm">

```cpp
int threshold = 3;

auto high = [threshold](const Task& t) {
    return t.priority() >= threshold;
};

auto bump = [&threshold]() {
    ++threshold;
};

std::vector<Task> tasks;
auto n = std::count_if(tasks.begin(), tasks.end(), high);
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">捕获方式</div>

- `[]`：不捕获
- `[x]`：按值捕获
- `[&x]`：按引用捕获
- `[=]` / `[&]`：全部按值/引用（谨慎）
- `[this]`：捕获当前对象

</div>

<div class="pitfall">
<span class="label">生命周期</span>
按引用捕获的变量必须活得比 Lambda 长；把 Lambda 存起来异步执行时，尤其要小心悬空引用。
</div>

</div>

</div>

##### 函数对象与 `std::function`

---

<div class="cols">

<div class="col-55">

```cpp
struct MatchPriority {
    int value;
    bool operator()(const Task& t) const {
        return t.priority() == value;
    }
};

std::count_if(tasks.begin(), tasks.end(),
              MatchPriority{3});

std::function<bool(const Task&)> pred =
    [](const Task& t) { return t.is_done(); };
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">三者关系</div>

- 函数指针：最简单，不能带状态
- 函数对象：可带状态，可内联
- Lambda：编译器生成的函数对象
- `std::function`：类型擦除，可存放任意可调用对象

</div>

<div class="small muted mt1">
<code>std::function</code> 有间接调用开销；模板算法直接接受 Lambda 通常更快。
</div>

</div>

</div>

##### 迭代器失效：容器修改后的陷阱

---

<div class="table-sm">

| 操作 | `vector` | `list` | `map` / `set` |
| :-- | :-- | :-- | :-- |
| 插入 | 可能全部失效（扩容） | 不影响其他元素 | 不影响其他元素 |
| 删除 | 被删位置及之后失效 | 只失效被删元素 | 只失效被删元素 |
| `push_back` | 扩容时全部失效 | — | — |

</div>

<div class="cols mt1">

<div class="col">

```cpp
// 错误：erase 后 it 失效
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it < 0) v.erase(it);   // 未定义行为
}
```

</div>

<div class="col">

```cpp
// 正确：erase 返回下一个有效迭代器
for (auto it = v.begin(); it != v.end(); ) {
    if (*it < 0) it = v.erase(it);
    else ++it;
}

// C++20：std::erase_if(v, pred);
```

</div>

</div>

##### C++20 Ranges：声明式管道

---

<div class="cols">

<div class="col-55 code-sm">

```cpp
#include <ranges>

auto result = tasks
    | std::views::filter([](const Task& t) {
          return !t.is_done();
      })
    | std::views::transform([](const Task& t) {
          return t.title();
      });

for (const auto& title : result) {
    std::cout << title << '\n';
}
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">特点</div>

- 管道写法，接近“声明做什么”
- 惰性求值：遍历时才计算
- 不产生中间容器
- 可与 STL 算法、范围 `for` 组合

</div>

<div class="tip">
<span class="label">与 STL 算法</span>
Ranges 不是替代 STL，而是在其上加了一层范围抽象；底层仍是迭代器与算法。
</div>

</div>

</div>

##### 主线案例：用 STL 组织任务

---

<div class="cols">

<div class="col-55 code-sm">

```cpp
std::vector<Task> tasks;
tasks.emplace_back(1, "写作业", 2);
tasks.emplace_back(2, "复习", 4);
tasks.emplace_back(3, "锻炼", 5);

std::sort(tasks.begin(), tasks.end(),
          [](const Task& a, const Task& b) {
              return a.priority() > b.priority();
          });

auto done = std::count_if(
    tasks.begin(), tasks.end(),
    [](const Task& t) { return t.is_done(); });

std::map<int, Task> by_id;
for (const Task& t : tasks) by_id.emplace(t.id(), t);
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">容器选择</div>

- 任务列表：`vector<Task>`（遍历、排序）
- 按编号查找：`map<int, Task>` 或 `unordered_map`
- 按优先级调度：`priority_queue<Task>`
- 去重：`set<int>` / `unordered_set`

</div>

<div class="tip">
<span class="label">组合</span>
同一批数据可以用不同容器组织：`vector` 负责顺序，`map` 负责索引，`priority_queue` 负责调度。不要试图用一个容器解决所有问题。
</div>

</div>

</div>

##### 课堂任务 13：任务统计

---

<div class="cols">

<div class="col-55">

<div class="card">

<div class="card-title">任务</div>

给定 `std::vector<Task> tasks`，用 STL 完成：

1. 按优先级从高到低排序并输出
2. 统计未完成任务数量
3. 计算所有任务优先级的平均值
4. 找出优先级最高的任务
5. 删除所有已完成任务（用 `erase` + `remove_if` 或 C++20 `erase_if`）

要求：不使用手写 `for` 循环完成统计（范围 `for` 输出可以）。

</div>

</div>

<div class="col-45">

<div class="card">

<div class="card-title">验收标准</div>

- 使用 `sort`、`count_if`、`accumulate`、`max_element`
- 比较器满足严格弱序
- 删除后容器大小正确
- 不越界、不使用失效迭代器
- 输出格式清晰

</div>

<div class="tip">
<span class="label">提示</span>
平均优先级 = <code>accumulate(..., 0, ...)</code> / <code>size()</code>；注意 <code>size()</code> 返回无符号类型。
</div>

##### 任务 13 参考实现

---

<div class="cols">

<div class="col-55 code-sm">

```cpp{.line-numbers}
#include <algorithm>
#include <numeric>
#include <vector>

std::sort(tasks.begin(), tasks.end(),
          [](const Task& a, const Task& b) {
              return a.priority() > b.priority();
          });

auto undone = std::count_if(
    tasks.begin(), tasks.end(),
    [](const Task& t) { return !t.is_done(); });

int sum = std::accumulate(
    tasks.begin(), tasks.end(), 0,
    [](int acc, const Task& t) {
        return acc + t.priority();
    });
double avg = tasks.empty()
    ? 0.0
    : static_cast<double>(sum) / tasks.size();

auto top = std::max_element(
    tasks.begin(), tasks.end(),
    [](const Task& a, const Task& b) {
        return a.priority() < b.priority();
    });

tasks.erase(
    std::remove_if(tasks.begin(), tasks.end(),
                   [](const Task& t) {
                       return t.is_done();
                   }),
    tasks.end());
```

</div>

<div class="col-45">

<div class="card">

<div class="card-title">要点</div>

- `sort` 比较器返回 `a.priority() > b.priority()` 实现降序
- `accumulate` 的初始值类型决定累加类型
- `max_element` 返回迭代器，需检查 `end()`
- `remove_if` 只移动元素，真正删除要靠 `erase`
- C++20 可写 `std::erase_if(tasks, pred)`

</div>

<div class="pitfall">
<span class="label">严格弱序</span>
比较器不能写 <code>&lt;=</code>；必须保证 <code>comp(a,a) == false</code>，否则 <code>sort</code> 行为未定义。
</div>

</div>

</div>

##### 常见陷阱

---

<div class="cols">

<div class="col">

**容器与迭代器**

- `vector` 扩容后继续使用旧迭代器
- `erase` 后不接收返回值
- `map[]` 意外插入默认值
- 用 `size()` 与 `int` 比较产生符号问题
- 在范围 `for` 中修改容器结构

</div>

<div class="col">

**算法与 Lambda**

- 比较器不满足严格弱序
- `remove_if` 后忘记 `erase`
- Lambda 按引用捕获局部变量后异步使用
- `std::function` 过度使用带来开销
- 对无序容器使用需要有序的算法

</div>

</div>

<div class="pitfall">
<span class="label">原则</span>
先选容器，再选算法；容器决定迭代器能力，算法决定对元素的要求。两者不匹配时，编译器会报错——这是好事。
</div>
