## 课堂小测参考答案

1. `struct point { int x, y; }; struct point pt; typedef struct { int x, y; } Point;`
2. `.` 优先级高于 `&`——`&p.x` 取成员地址；`p.x` 是 int 值，scanf 需要地址
3. a.x 仍是 1——结构体整体赋值是"复制"（把整段内存复制过去）
4. 结构体作参数是"复制"（整个结构体的副本，改形参不影响实参）；数组作参数是"共享"（传地址，能改原数组）
