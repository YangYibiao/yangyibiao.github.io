# 第4-5周讲义（4 次课 × 100 分钟）

课件：4-1-selection-i（第4周周二）、4-2-selection-ii（第4周周三）、5-1-loops-i（第5周周二）、5-2-loops-ii（第5周周三），均为连续课件，从头翻到尾。

## 第4周周二：选择结构（上）—— 结构化算法、逻辑运算与 if（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾：变量/IO/运算符；回顾猜数字游戏里的 `if (guess == reward)`——程序开始会"判断"了。
2. 结构化算法与三种基本结构（课件页）：顺序/选择/循环；自顶向下、逐步细化；本节学"选择"。

### 二、关系、判等与逻辑运算（30 分钟）
1. 逻辑表达式：C 中比较产生整数 0（假）/ 1（真）。
2. 关系运算符 < > <= >=：优先级低于算术；i + j < k – 1 的含义。
3. i < j < k 的坑：左结合，实际是 (i < j) < k；正确写法 i < j && j < k。
4. 判等运算符 == !=：优先级低于关系运算符；**== 与 = 混淆是经典错误**（现场演示 if (i = 0) 的后果）。
5. 逻辑运算符 ! && ||：非零即真；**短路计算**（(i != 0) && (j / i > 0) 防除零）；副作用可能不产生（i > 0 && ++j > 0）；优先级与结合性。

### 三、if 语句与复合语句（20 分钟）
1. if (表达式) 语句：圆括号必须；表达式非零则执行。
2. 范围判定：if (0 <= i && i < n)。
3. 复合语句 { }：控制多条语句；大括号习惯。

### 四、else 子句与嵌套（15 分钟）
1. if/else 形式与单行写法；max 例子。
2. 嵌套 if（min of three 现场演示）；大括号让层次清晰；多用大括号的优点。

### 五、现场演示（15 分钟）
1. min of two（课件页）：if/else 各一条语句时花括号可省略。
2. min of three：嵌套 if else。
3. 闰年判断：**对照流程图写代码**（课件图），int leap 标志变量的写法。

### 六、课堂小测（5 分钟）
题目见 4-1 课件「课堂小测」页，参考答案：
1. 不能；正确写法 i < j && j < k；
2. if (i = 0) 先赋值 0 再判断，恒为假——常见错误；if (i == 0) 才是判等；
3. i 为 0 时不计算右操作数，避免除零；
4. 用复合语句：if (…) { 语句1; 语句2; }。

### 七、小结与作业（5 分钟）
1. 小结：比较产生 0/1；优先级：算术 > 关系 > 判等 > 逻辑；if/else + 大括号。
2. 作业：OJ 周练；写程序：输入两个整数，若 a > b 交换后按升序输出；预习：级联 if 与 switch（周三）。

## 第4周周三：选择结构（下）—— 级联 if、条件表达式与 switch（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾 if/else 与逻辑运算；抛问题：成绩分五档（优秀/良好/中等/及格/不及格）怎么写最清晰？——引出级联 if。

### 二、级联式 if 与经纪人佣金（20 分钟）
1. 级联 if：else if 对齐写法，避免过度缩进；模板 if/else if/…/else。
2. 案例 broker.c：佣金表 → 级联 if 实现 → 最低收费的二次判断。

### 三、悬空 else（10 分钟）
1. else 与最近的未配对 if 匹配；缩进陷阱示例。
2. 用大括号明确归属；正确缩进。

### 四、条件表达式（15 分钟）
1. 表达式1 ? 表达式2 : 表达式3；三元；分阶段求值。
2. 例子 k = i > j ? i : j；(i >= 0 ? i : 0) + j 的括号必要性；printf/return 中的应用；谨慎使用。

### 五、布尔值（10 分钟）
1. C89 传统：int flag + #define TRUE/FALSE + if (flag)。
2. C99：_Bool（只存 0/1）与 <stdbool.h>（bool/true/false）——推荐。

### 六、switch 语句与 break（20 分钟）
1. 级联 if → switch 对照（grade 例子）；更易读、通常更快。
2. 形式与规则：控制表达式为整数；case 常量表达式；重复标签非法；default 位置任意。
3. 多个 case 共用语句（case 4: case 3: case 2: case 1:）；同行写法。
4. **break 的作用**：漏写会"穿透"（现场演示 GoodAveragePoor…）；故意穿透要写 /* FALL THROUGH */。

### 七、案例与演示（10 分钟）
1. date.c：法律日期格式（switch 给日期加 st/nd/rd/th + 月份单词）——现场演示。
2. 闰年化简（课件页）：级联 if → 逻辑表达式直接赋值，三种写法对比。

### 八、课堂小测与小结（5 分钟）
题目见 4-2 课件「课堂小测」页，参考答案：
1. 判定一系列条件、一个为真即停止；else if 与 if 对齐书写，避免过度缩进；
2. i 和 j 中较大的那个；可以嵌套但难读，谨慎；
3. 控制会"穿透"到下一个 case；多个 case 标签并列后跟共用语句；
4. else 与最近的未配对 if 配对；用大括号明确归属。
作业：OJ 周练；写程序：输入成绩（0-100）输出五档评级（用 switch）；预习：循环结构（第5周）。

## 第5周周二：循环结构（上）—— while 与 do-while（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾 if/switch；抛问题：怎么打印 1 到 100 的平方？写 100 行 printf 吗？——引出循环。

### 二、while 语句（30 分钟）
1. 重复语句概念与三种循环概览（while / do-while / for 的判定位置区别）。
2. while 形式与执行流程：先判定后执行；最小 2 的幂逐步跟踪（板书演算）。
3. 复合语句做循环体；倒计数示例；终止后控制表达式必为假；循环体可能一次都不执行；多种写法（i-- 内联）。
4. 无限循环 while (1)：靠 break/return 跳出。

### 三、案例：平方表与数列求和（15 分钟）
1. square.c：scanf 读条目数 → while 打印 i 与 i*i（%10d 对齐）。
2. sum.c：0 终止输入的数列求和——哨兵值（sentinel）模式。

### 四、do-while 语句（15 分钟）
1. do 语句形式；先执行后判定；与 while 的唯一区别：至少执行一次。
2. 大括号习惯（避免被误读为 while）。
3. 案例 numdigits.c：反复除以 10 计位数——0 也有一位，正是 do-while 的适用场景。

### 五、break 与 continue（15 分钟）
1. break：跳出最内层循环/switch；素数判定的提前退出；for(;;) + break 的交互式输入模式；嵌套时只跳一层。
2. continue：跳到循环体末尾之前（本轮跳过）；与 break 的对比表；改写示例（if (i != 0) 等价写法）。

### 六、课堂小测（5 分钟）
题目见 5-1 课件「课堂小测」页，参考答案：
1. do-while 先执行后判定，循环体至少执行一次；while 可能一次都不执行；
2. 无限循环；循环体内用 break 或 return 跳出；
3. break 转移到循环体末尾之后（跳出循环）；continue 转移到循环体末尾之前（留在循环内）；
4. 反复 n /= 10 并计数 digits++，直到 n 为 0。

### 七、小结与作业（10 分钟）
1. 小结：while = 先判定后执行；do-while = 至少一次；break/continue 控制跳出与跳过。
2. 作业：OJ 周练；写程序：输入 n 打印 1~n 的平方（while 版）；用 while 重写猜数字；预习：for 语句（周三）。

## 第5周周三：循环结构（下）—— for 与算法案例（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾 while/do-while；抛问题：计数循环三件事（初始化/判定/递增）散落在三行，能不能写在一起？——引出 for。

### 二、for 语句（30 分钟）
1. for 形式（表达式1/2/3 职责）与倒计数示例；与 while 的等价转换。
2. i-- 与 --i 在表达式3中等价（通过等价 while 理解）；表达式1/3 只看副作用。
3. 常见惯用法四式（0..n-1、1..n、n-1..0、n..1）与三种常见错误（方向写反、== 、差一）。
4. 省略表达式：省 1/省 3/省 1+3（等价 while）/省 2（默认真，for(;;) 无限循环）。
5. C99：for (int i = ...) 声明循环变量；作用域限于循环；多变量声明。
6. 逗号运算符：多个初始化/多变量递增；优先级最低、左结合。

### 三、案例与嵌套循环（20 分钟）
1. 平方表 for 版：与 while 版对比（三件事一行写完）。
2. **星号塔（stars.jpg，现场演示）**：外层控制行数、内层控制每行星号个数；"外层每执行一次，内层完整一轮"。

### 四、算法案例（25 分钟）
1. 数据交换（临时变量三行）、累加（初始 0）、累乘（初始 1，注意溢出）。
2. 素数判断（prime.jpg）：2~n-1 找约数 + break；用 d < n 判定是"提前退出"还是"正常结束"；预告 sqrt 优化。
3. 非完全平方数的和（perfectSquare.gif）：sqrt + 强制转换判定完全平方数 + continue 跳过——循环与数学库第一次合作。

### 五、课堂小测（5 分钟）
题目见 5-2 课件「课堂小测」页，参考答案：
1. n 次（i = 0, 1, ..., n-1）；
2. 无限循环；表达式1 不初始化、表达式2 默认真、表达式3 不递增；
3. 外层控制行数（i），内层控制每行星号个数（j）；
4. `int sum = 0; for (int i = 1; i <= 100; i++) sum += i;`；100! 远超 int，建议 double 或 long long。

### 六、小结与作业（10 分钟）
1. 小结：for = 计数循环利器；嵌套循环的层数概念；累加器/累乘器经典模式；break/continue 与算法的结合。
2. 作业：OJ 周练；写程序：打印乘法口诀表（嵌套循环）；输出 2~100 的全部素数；预习：函数（第6周）。
