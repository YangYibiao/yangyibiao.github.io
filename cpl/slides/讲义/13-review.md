# 第15周讲义（2 次课 × 100 分钟）

课件：15-1-project（第15周周二，期末项目指导与答辩）、15-2-review（第15周周三，总复习与答疑，最后一课）。

## 第15周周二：期末项目指导与答辩（100 分钟）

1. 项目要求回顾（20 分钟）：三项交付物（代码/答辩/技术文档）+ 评分维度表；强调"每个组员都要能讲清整体结构"。
2. 答辩流程与评分标准（20 分钟）：演示 3-5 分钟 + 讲解 3-5 分钟 + 提问 3-5 分钟；演示前自己多跑几遍、准备最小可运行版本。
3. 常见问题与准备建议（20 分钟）：三个常见失分点（演示崩溃/讲不清结构/答不上为什么）；AI 用过的部分必须自己读懂每一行。
4. 答疑与项目工作坊（30 分钟）：分组答疑、现场看各组进度。
5. 预告：周三总复习（最后一课），考试周项目答辩 + 闭卷机试。

## 第15周周三：总复习与答疑（100 分钟，最后一课）

1. 全学期知识地图（15 分钟）：从"程序需要什么"反推——本周次表与第 1 周课程地图一致。
2. 易错点串讲（30 分钟）：类型与运算（整数除法/溢出 UB/类型转换/浮点比较）→ 控制与函数（if 赋值陷阱/switch 穿透/循环三要素/传值 vs 传址/递归两要素）→ 指针与内存（&* 互逆/a[i]==*(a+i)/野指针/malloc 配 free/strcmp 不是 ==）→ 文件与结构体（整体赋值不能比较/->/fopen 检查 NULL/fgetc 与 EOF/fgets 与 NULL/头文件保护）。
3. 考试形式与评分（10 分钟）：闭卷机试、评分维度；备考建议（OJ 过一遍、手写经典小程序、易错点清单）。
4. 模拟练习（20 分钟）：三题参考答案见下。
5. 一学期的旅程 + 课程结语（15 分钟）：旅程页 + 结语页收尾。

## 模拟练习参考答案

1. `char line[101]; fgets(line, 101, stdin);` 遍历直到 `\0`，用 `isupper/islower/isdigit`（<ctype.h>）或区间判断分类计数；注意 fgets 读入的 `\n` 算"其他字符"。
2. `int *p = a, *pmax = a; for (p = a; p < a + n; p++) if (*p > *pmax) pmax = p; printf("max=%d index=%d\n", *pmax, (int)(pmax - a));`（> 保证重复取第一次）。
3. `struct Student s[5];` 用选择排序按 `score` 降序，交换整个结构体（`tmp = s[i]; s[i] = s[j]; s[j] = tmp;`）；并列保持输入顺序——交换条件用 `>` 不用 `>=`（冒泡/插入天然稳定，选择排序注意比较方向）。
