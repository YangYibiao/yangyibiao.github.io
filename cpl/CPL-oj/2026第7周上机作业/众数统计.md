# OJ 题目草稿：众数统计（2026 秋 第7周 · 排序+查找综合）

## 题面

OJ【XXXX】众数统计

编写程序：从键盘输入 n 个整数（**无序**，1 ≤ n ≤ 100），先排序，再统计出现次数最多的数（众数）及其出现次数并输出。若多个数出现次数并列最多，输出其中**最小**的一个。

- 输入格式：第一行一个整数 n；第二行 n 个整数，空格分隔。
- 输出格式：一行两个整数：众数与出现次数，空格分隔。

样例输入 1：
```
7
1 2 2 3 2 5 7
```
样例输出 1：
```
2 3
```

样例输入 2（并列取最小）：
```
6
3 1 3 1 5 4
```
样例输出 2：
```
1 2
```

## 考察点

1. 数组读入与排序（冒泡/选择/插入任选，main 版）
2. 有序数组一遍扫描统计（相邻相同计数）
3. 边界处理：段结算时机（i == n 时也要结算最后一段）

## 参考解（main 版）

```c
#include <stdio.h>
int main(void) {
    int a[100], n, i, j;
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }
    /* 冒泡排序: 从小到大 */
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    /* 一遍扫描: 统计每段长度, 找最长段 (升序下从左往右, 并列自然保留最小的) */
    int best = a[0], best_cnt = 1;
    int cur = a[0], cur_cnt = 1;
    for (i = 1; i <= n; i++) {
        if (i < n && a[i] == cur) {
            cur_cnt++;
        } else {
            if (cur_cnt > best_cnt) {
                best = cur;
                best_cnt = cur_cnt;
            }
            if (i < n) {
                cur = a[i];
                cur_cnt = 1;
            }
        }
    }
    printf("%d %d\n", best, best_cnt);
    return 0;
}
```
