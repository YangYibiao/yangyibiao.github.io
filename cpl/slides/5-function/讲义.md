# 第6-7周讲义（4 次课 × 100 分钟）

课件：6-1-functions-i（第6周周二）、6-2-functions-ii（第6周周三）、7-1-recursion（第7周周二）、7-2-scope-preprocess（第7周周三）。

## 第6周周二：函数（I）—— 定义、调用与参数传递（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾第 5 周循环案例：素数判断的循环写了三遍（课堂编码时发现重复）——引出"把重复的代码打包"。
2. 软件设计原则页：模块化、每个函数只做一件事。

### 二、函数的定义与调用（30 分钟）
1. 函数概念与一般形式：返回类型 函数名(参数) { 语句 }；double average(double a, double b)。
2. 计算平均值案例：avg.c 从 main 里"抽出" average 函数，对照改写前后。
3. 显示倒计时、双关语改进版：void 函数与带参函数。
4. 函数调用的执行流程：跳进函数、执行、返回调用点。

### 三、函数声明（15 分钟）
1. 为什么需要声明（编译器从上往下读）；函数原型形式。
2. 声明与定义的顺序问题：先声明后使用。

### 四、参数传递（20 分钟）
1. 实参/形参的概念；按值传递（形参是实参的副本——第10周指针再讲传址）。
2. 演示页（新增）：swap 为什么不生效——传值调用只交换副本，函数"没效果"；留悬念：第 10 周用 swap(&x, &y) 解决。
3. 实际参数的转换：类型不匹配时按赋值规则转换。

### 五、return 与程序终止（10 分钟）
1. return 语句的作用与形式；void 函数中 return; 的用法。
2. return 0 与 exit(0) 的区别（exit 在任意位置立即终止，需 stdlib.h）。

### 六、课堂小测（5 分钟）
题目见 6-1 课件「课堂小测」页，参考答案：
1. 函数首部（返回类型+函数名+参数表）与函数体；return 把值交还给调用者；
2. 声明（或定义在前）；返回类型 函数名(参数类型表);；
3. 按值传递；形参是实参的副本，改形参不影响实参；
4. void 表示不返回任何值；exit(0) 在任意位置立即终止程序（需 <stdlib.h>），return 只结束当前函数。

### 七、小结与作业（10 分钟）
1. 小结：函数 = 带名字的代码块；定义/声明/调用三件套；按值传递。
2. 作业：OJ 周练；把第5周的"非完全平方数和"程序改写为函数版；预习：函数编码与栈（周三）。

## 第6周周三：函数（II）—— 函数化改造与函数栈（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾函数三件套；抛问题：函数被调用时，计算机内部发生了什么？——引出调用栈。

### 二、函数化改造演示（30 分钟）
1. 判定素数（is_prime）：把第5周的循环+break 逻辑抽成 int is_prime(int n)。
2. leap.c：闰年判断函数化；1/0 作为布尔返回值的惯例。
3. primes.c：用 is_prime 打印 2~100 的全部素数——函数复用第一次体现。
4. stars.c：print_stars(n) 打印一行星号（为第5周星号塔重构埋钩子）。

### 三、函数与栈（20 分钟）
1. 调用栈概念：压栈（返回地址、局部变量、参数）、弹栈。
2. 局部变量的生命周期：函数返回后消失。
3. 配合动画页 function-and-stack.html 演示（点击链接打开动画）。

### 四、课堂编码（25 分钟）
1. 学生现场完成三个改写：average / is_prime / print_stars。
2. 巡视检查；强调"每个函数只做一件事"。

### 五、课堂小测（5 分钟）
题目见 6-2 课件「课堂小测」页，参考答案：
1. int（返回 1 表示素数，0 表示不是）；
2. 1 = 闰年，0 = 平年（布尔标志的惯例）；
3. 压栈保存返回地址与局部变量；函数返回后局部变量消失；
4. print_stars(n)（void 返回）。

### 六、小结与作业（10 分钟）
1. 小结：函数化 = 复用 + 清晰；栈是函数调用的幕后机制。
2. 作业：OJ 周练；把第5周"星号塔"改写为 print_stars + 循环两层；思考：函数能调用自己吗？预习：递归（第7周周二）。

## 第7周周二：递归函数（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾函数与栈（第6周）；抛问题：函数能不能调用自己？——引出递归。

### 二、递归入门（25 分钟）
1. 递归概念（0-1 课件的递归页 + 5-1 旧课件）：函数直接或间接自己调用自己。
2. 递归的定义（n! 例子）：基准情形 + 递归情形。
3. 阶乘递归实现与执行过程：递推/回归、层层压栈（呼应第6周函数栈）；递归深度与栈溢出。

### 三、经典案例（35 分钟）
1. Fibonacci：两个递归调用；指出重复计算代价（f(2) 被算多遍）。
2. 递归 gcd：与第5周循环版对比——递归更贴近数学定义。
3. Hanoi 塔：问题 → 三步思路 → 代码；强调"把问题交给递归"（64 盘需 2^64-1 步）。

### 四、常见错误与课堂编码（20 分钟）
1. 两个常见错误：缺基准情形、问题不缩小。
2. 现场编码：递归求和、递归求幂、printd（整数打印）。

### 五、课堂小测（5 分钟）
题目见 7-1 课件「课堂小测」页，参考答案：
1. 基准情形（终止条件）+ 递归情形（规模缩小后调用自身）；
2. 5 层（f(5) 到 f(1)，逐层压栈）；
3. fib(2) 被算 3 次（fib(5)→fib(3)+fib(4) 两路都算）——朴素递归的重复计算代价；
4. 递归适合"自我相似"的问题（树形结构、分治），循环适合简单重复；递归更接近数学定义但开销更大。

### 六、小结与作业（5 分钟）
1. 小结：递归 = 基准情形 + 缩小规模；递归与栈的关系。
2. 作业：OJ 周练；写递归版求 1+2+...+n 与 x^n；预习：作用域与预处理（周三）。

## 第7周周三：作用域、预处理与 AI 赋能（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾递归；抛问题：同一个变量名在不同函数里为什么互不干扰？——引出作用域。

### 二、作用域与生命期（30 分钟）
1. 四类作用域简化讲：块作用域（局部变量/形参）与文件作用域（全局变量）；内层屏蔽外层。
2. 局部 vs 全局变量：全局变量少用为妙。
3. 生命期：动态（默认）vs 静态（static 局部变量"带记忆"，现场演示计数例子）。

### 三、预处理（30 分钟）
1. 预处理概念：# 开头的命令在编译前处理。
2. #include 文件包含：尖括号 vs 引号；头文件放声明。
3. 宏定义：类对象宏（#define PI，行末无分号）；带参宏（MAX 例子，必须加括号）；MAX(i++, j) 副作用坑；宏 vs 函数。
4. 条件编译：#ifdef DEBUG 调试开关（为第14周多文件铺垫）。

### 四、AI 赋能程序设计 I（15 分钟）
1. 函数化重构：把长 main 交给 AI 拆函数并解释。
2. 理解递归：让 AI 画 f(4) 调用过程、讲 Hanoi 塔。
3. 出题：让 AI 出 5 道递归题，先做后对。
4. 规则：先自己写，再让 AI 改。

### 五、课堂小测（5 分钟）
题目见 7-2 课件「课堂小测」页，参考答案：
1. 局部变量：函数体内块作用域；全局变量：文件作用域；内层同名变量遮蔽外层；
2. static 局部变量只初始化一次、函数返回后保留原值（"带记忆"）；普通局部变量每次调用重新创建；
3. 宏是纯文本替换，不加括号会因优先级出错；MAX(i++, j) 中 i 会自增两次；
4. 选择性编译代码（调试开关、跨平台）。

### 六、小结与作业（10 分钟）
1. 小结：作用域决定"谁看得见"，生命期决定"活多久"；预处理 = 编译前的文本加工。
2. 作业：OJ 周练；写一个用 static 计数的函数；用 #define 定义几个宏并说明展开结果；预习：一维数组（第8周）。
