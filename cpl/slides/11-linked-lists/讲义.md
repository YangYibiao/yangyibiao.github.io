# 第13周周三：链表（100 分钟）

课件：13-2-linked-list（11 页：动态内存 malloc/free 浓缩页 + 链表概念/结点/创建/->/头插/搜索/删除/有序链表/零件数据库改进版）。

## 时间计划

1. 回顾与导入（10 分钟）：回顾结构体；抛问题：数组长度编译时定死、插入删除要搬家——能不能"按需创建、随连随拆"？——引出链表。
2. 动态内存（15 分钟）：malloc/free 浓缩页——malloc 借不清零、NULL 检查、free 归还、内存泄漏与悬空指针。
3. 链表与结点（20 分钟）：链表概念（结点+指针串起来）、声明结点类型（`struct node *next` 必须用标记）、创建结点（malloc + 两步赋值）。
4. 操作（35 分钟）：`->` 运算符（`(*p).x` 的缩写）→ 头插（两步指针，顺序不能反）→ 搜索（遍历惯用法）→ 删除（追踪指针：找到/绕过/free，删头结点要更新头指针——课件已补代码）。
5. 零件数据库改进版 + 有序链表（15 分钟，弹性）。
6. 课堂小测与小结（5 分钟）：答案见下。

## 课堂小测参考答案

1. 数据 (value) + 指向下一个结点的指针 (next)
2. node 是结构体标记而不是 typedef 名——标记只有跟在 `struct` 后面才有意义
3. `(*p).value`（`.` 优先级高于 `*`，不加括号就变成 `*(p.value)`，而 p 不是结构体）
4. 改两个指针：先 `new_node->next = first;` 再 `first = new_node;`——顺序不能反（先接上后面的链，再改头指针，否则后面的链就丢了）
