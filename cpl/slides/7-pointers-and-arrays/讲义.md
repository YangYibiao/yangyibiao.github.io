## 第10周周二：指针基础（上）—— 地址与指针变量（100 分钟）

课件 10-1-pointers-i（9 页：指针变量/为什么需要地址/声明/&/*(上)/*(下)/指针赋值(上)(下)）。

### 一、回顾与导入（10 分钟）
1. 第 9 周的悬念今天揭晓："函数能改原数组，第 10 周解释为什么"——因为数组名传的是==地址==。
2. 抛出问题：变量住在内存的什么位置？能不能"按地址"访问它？

### 二、指针变量（25 分钟）
1. 地址的概念：内存按字节编号，变量的地址 = 它的首字节编号（配合图示）。
2. 指针变量：专门存放地址的变量；`int *p;` 中 p 的类型是"指向 int 的指针"。
3. 声明指针变量：`int *p;` / 多个声明的陷阱（`int *p, q;` 只有 p 是指针）。

### 三、& 和 * 两个运算符（30 分钟）
1. `&` 取地址：`p = &x;`；呼应 scanf 里的 `&`（终于知道为什么了）。
2. `*` 间接寻址：`*p` 等价于 p 指向的那个变量；可读可写（`*p = 10;`）。
3. 互逆关系：`*&x` 等价于 x；`&*p` 等价于 p。
4. 未初始化指针解引用的危险：未定义行为（*p 上下两页演示）。

### 四、指针赋值（25 分钟）
1. 指针赋值：`q = p` 让两个指针指向同一对象；任意多个指针可指向同一对象。
2. `q = p` 与 `*q = *p` 的区别（复制地址 vs 复制值）。

### 五、课堂小测与小结（10 分钟）
题目见 10-1 课件「课堂小测」页，参考答案：
1. 存的是地址（某变量的首字节编号）；p 的类型是 `int *`（指向 int 的指针）；
2. `&x` 取 x 的地址；`*p` 访问 p 指向的对象；是互逆运算（`*&x` = x）；
3. `*p = 10` 改的是 p 指向的那个变量的值；`p = &x` 改的是 p 本身（让它指向 x）；
4. 未定义行为——p 没指向任何合法对象，可能读到垃圾、改到任意内存或直接崩溃。
作业：OJ 周练；用指针打印一个变量的地址和值；预习：传址调用（周三）。

## 第10周周三：指针基础（下）—— 传址调用与练习（100 分钟）

课件 10-2-pointers-ii（7 页 + 课堂编码）。

### 一、回顾与导入（10 分钟）
1. 回顾 &/*；第 8 周 swap 传值失败的悬念今天揭晓——传地址就能改到实参。

### 二、传址调用（25 分钟）
1. decompose 的故事：传值改不了实参，传指针就能改（`*int_part = (long) x;`）。
2. 指针作为参数页：scanf 的参数必须是指针；`scanf("%d", &p)` 是错的；decompose 少 & 的灾难性后果（改未知地址）。

### 三、案例与 const（25 分钟）
1. 程序: 查找数组中最大和最小的元素（两页：任务 + 参考代码）——用指针参数一次带回两个结果。
2. const 保护参数：`const int *p` 表示"只读"，防止函数误改。
3. 指针作为返回值：max(&i, &j) 返回较大值的地址；**永远不要返回指向自动局部变量的指针**。

### 四、课堂编码（25 分钟）
1. 写 `void swap(int *a, int *b)`，在 main 里验证真的交换了。
2. 写 `void max_min(int a[], int n, int *max, int *min)`。
3. 挑战：写 `int *max(int *a, int *b)`，返回较大值的地址。

### 五、课堂小测与小结（15 分钟）
题目见 10-2 课件「课堂小测」页，参考答案：
1. C 是值传递——传值改不了实参；传地址后函数通过 `*a`/`*b` 改到调用者的变量；
2. i、d 的==值==被当成地址，函数会修改未知内存；有原型时编译器报类型不匹配，没原型则灾难无声；
3. 不能——返回后局部变量已消亡，得到悬空指针；
4. `const int *p`: 不能通过 p 改指向的对象（p 本身可改）；`int * const p`: p 本身不能改，指向的对象可以。
作业：OJ 周练；写 `void min_max(int a[], int n, int *min, int *max)`；预习：指针与数组（第11周）。

## 第11周周二：指针与数组（上）—— 指针算术（100 分钟）

课件 11-1-pointer-arrays-i（7 页：指针算术/加减整数/相减/比较/数组处理/*和++(上)(下)）。

### 一、回顾与导入（10 分钟）
1. 回顾 &/*；抛问题：数组名是什么？指针能指向数组元素吗？

### 二、指针的算术运算（30 分钟）
1. 指针 + 整数：`p + 1` 指向"下一个元素"（地址加的是元素大小，不是 1 字节）。
2. 指针 - 整数；两个指针相减 = 元素个数差（不是字节差）。
3. 比较指针：`p < q` 判断先后位置——只对同一数组的元素有意义。

### 三、用指针处理数组（30 分钟）
1. `for (p = &a[0]; p < &a[N]; p++)` 的遍历法（&a[N] 合法）。
2. `*p++` 的含意（先取值再移动）与四行对照表：`*p++` / `(*p)++` / `*++p` / `++*p`。
3. `*` 和 `--` 的组合：回到第 8 周的栈——push 用 `*top_ptr++ = i`，pop 用 `return *--top_ptr`。

### 四、课堂练习（15 分钟）
1. 用指针遍历数组求和、找最大（现场写）。
2. 辨析：`*p++` 与 `(*p)++` 在具体代码里的差异（给初值走一遍）。

### 五、课堂小测与小结（15 分钟）
题目见 11-1 课件「课堂小测」页，参考答案：
1. 指向下一个 int 元素；地址增加 sizeof(int) = 4 字节；
2. 元素个数差（指针相减自动除以元素大小）；
3. 等价于 `*(p++)`：先取 p 当前指向的值，再把 p 移向下一个元素；
4. 必须指向==同一数组==的元素，否则结果无意义（未定义行为）。
作业：OJ 周练；用指针重写"最大值及位置"程序；预习：数组名与多维数组指针（周三）。

## 第11周周三：指针与数组（下）—— 数组名与数组实参（100 分钟）

课件 11-2-pointer-arrays-ii（9 页：数组名/数列反向(两页)/数组实参(三页)/指针作数组名/多维(三页)）。

### 一、回顾与导入（10 分钟）
1. 回顾指针算术；抛问题：数组名到底是不是指针？`a == &a[0]` 成立吗？

### 二、数组名作为指针（20 分钟）
1. `a+i` 等价于 `&a[i]`，`*(a+i)` 等价于 `a[i]`。
2. 数组名可以当指针用，但==不能给数组名赋新值==（`a++` 是错的）；想走就用指针变量。
3. 案例：数列反向（指针版，两页：任务 + 参考代码）——第 6 周下标版的指针重写。

### 三、数组型实际参数（25 分钟）
1. 形参 `int a[]` 与 `int *a` 完全等价——**第 9 周"函数能改原数组"的悬念正式揭晓**（传的是地址）。
2. 数组参数的四条后果：能改元素、sizeof 失效、长度必须另传、可以传数组的一部分（`find_largest(&b[5], 10)`）。
3. 声明不等价：`int a[10]` 留出 10 个整数的空间，`int *a` 只留指针的空间。

### 四、多维数组与指针（25 分钟，元素与行为主，列选讲）
1. 元素：行主序 + `p = &a[0][0]` 一路 `*p = 0`（第 6 周行主序的兑现）。
2. 行：`a[i]` 是指向第 i 行首元素的指针；处理一维数组的函数可直接处理二维数组的行。
3. 列（选讲）：`int (*p)[NUM_COLS]` 指向"长度为 NUM_COLS 的数组"，`(*p)[i]` 括号不能少。

### 五、课堂小测与小结（20 分钟）
题目见 11-2 课件「课堂小测」页，参考答案：
1. 数组名等价于首元素地址，`a == &a[0]` 成立；但不能给 a 赋值或自增——它不是左值；
2. 完全等价：`a[i]` 就是 `*(a+i)`；
3. 合法——编译器把 `p[i]` 视为 `*(p+i)`；
4. `int (*)[NUM_COLS]`（指向长度为 NUM_COLS 的 int 数组的指针）；`p++` 移到下一行的开头。
作业：OJ 周练；写 `void min_max(int a[], int n, int *min, int *max)`；用指针重写数列反向；预习：字符串（第12周）。
