## 第4周周二：选择结构（上）—— 结构化算法、逻辑运算与 if（100 分钟）

### 一、回顾与导入（5 分钟）
1. 回顾：变量/IO/运算符；回顾猜数字游戏里的 `if (guess == reward)`——程序开始会"判断"了。
2. 结构化算法与三种基本结构（课件页）：顺序/选择/循环；本节学"选择"。

### 二、if 语句与 else 子句形式（10 分钟）
1. if 语句形式：if (表达式) 语句——圆括号必须；表达式非零则执行、为零跳过。
2. else 子句形式：if (表达式) 语句 else 语句——值为 0 走 else；内部语句短可写一行（max 例子）。
3. 预告："表达式里能写什么？"——接下来讲关系、判等与逻辑运算符；要控制多条语句用复合语句 { }（后面讲）。

### 三、关系、判等与逻辑运算（25 分钟）
1. 逻辑表达式：C 中比较产生整数 0（假）/ 1（真）。
2. 关系运算符 < > <= >=：优先级低于算术；i + j < k – 1 的含义。
3. i < j < k 的坑：左结合，实际是 (i < j) < k；正确写法 i < j && j < k。
4. 判等运算符 == !=：优先级低于关系运算符；**== 与 = 混淆是经典错误**（演示页：if (x = 5)——条件恒真且 x 被悄悄改值，编译器不报错；防御写法 5 == x，写错成 5 = x 编译器直接报错）。
5. 逻辑运算符 ! && ||：非零即真；**短路计算**（(i != 0) && (j / i > 0) 防除零）；副作用可能不产生（i > 0 && ++j > 0）；优先级与结合性。

### 四、范围判断、复合语句与嵌套（15 分钟）
1. 范围判断：if (0 <= i && i < n)；连写 0 <= i < n 是错的（呼应 i<j<k 陷阱）——if 最高频用法。
2. 复合语句 { }：控制多条语句；大括号习惯。
3. else 嵌套与对齐：缩进对齐、最好加大括号；多用大括号的优点（悬空 else 预告）。

### 五、现场演示（25 分钟，全部"先问题后代码"两页式）
1. min of two：第 1 页只给问题（不提示做法），学生先写再翻页；第 2 页参考代码——"先假定再修正"思路，输入 5 3 → min(5, 3) = 3，建议养成加花括号的习惯。
2. min of three（四页：问题 → 解法一 → 挑战 → 解法二）：① 问题页不提示做法，学生先写；② 参考代码 1 嵌套版（输入 8 3 5 → min = 3）；③ 挑战页追问"还有另一种写法——不用嵌套，延续先假定再修正，min 先取 a 逐个替换"；④ 参考代码 2 单分支版（min=a; if(b<min) min=b; if(c<min) min=c;）——借此讲"if 不配 else 也合法"（为第 6 周数组铺垫）。
3. 闰年判断：第 1 页只给问题（闰年规则 + 流程图，不提示做法），学生先写再翻页；第 2 页参考代码——三层嵌套对应流程图三个判断框，leap 标志变量"算"和"用"分离；测试 2024/1900/2000；预告化简版周三讲。
4. 三角形判定（现场边写边讲）：① 声明+scanf → ② 三个条件用刚学的 && 连起来 → ③ 补 printf 分支；边界 1 2 3（相等不行）；&& 短路。
5. 奇偶判断（现场边写边讲）：① 先用 % 写直白版 → ② 问"第 3 周的位运算能不能判？"→ n & 1 试写一遍；结论：先写对、再谈快。

### 六、课堂习题（10 分钟）
课件「课堂习题」页两道题，参考答案：
1. 正负判定：`if (n > 0) … else if (n < 0) … else …`（或嵌套：先 n >= 0 再分正零）；注意 else if 是 4-2 的正式内容，这里允许用嵌套写。

### 七、课堂小测与小结（10 分钟）
题目见 4-1 课件「课堂小测」页，参考答案：

## 第5周周二：循环结构（上）—— while 与 do-while（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾 if/switch；抛问题：怎么打印 1 到 100 的平方？写 100 行 printf 吗？——引出循环。

### 二、while 语句（30 分钟）
1. 重复语句概念与三种循环概览（while / do-while / for 的判定位置区别）。
2. while 形式与执行流程：先判定后执行；最小 2 的幂逐步跟踪（板书演算）。
3. 复合语句做循环体；倒计数示例；终止后控制表达式必为假；循环体可能一次都不执行；多种写法（i-- 内联）。空语句陷阱页（多打分号 → 死循环/if 空体）为==弹性内容==，时间不够可快讲或跳过。
4. 无限循环 while (1)：靠 break/return 跳出。

### 三、案例：平方表与数列求和（15 分钟）
1. square.c（拆两页：任务页 + 参考代码页）：第 1 页只给题目和样例输出（方向提示：两列右对齐，%10d 字段宽度），学生边听边写；第 2 页参考代码——i <= n 计数循环、两条语句用大括号、%10d 对齐。
2. sum.c（拆两页：任务页 + 参考代码页）：第 1 页题目 + 样例 + 方向提示（0 是哨兵值，不参与求和），学生边听边写；第 2 页参考代码——"读一个、判一个、加一个"、sum 初值必须为 0、哨兵值模式。

### 四、do-while 语句（15 分钟）
1. do 语句形式；先执行后判定；与 while 的唯一区别：至少执行一次。例子改为输入校验（do { scanf } while (n <= 0)）——"先读后判"场景 do-while 正合适，while 版要预读一次很别扭（与数列求和的预读对比）。
2. 大括号习惯（避免被误读为 while）。
3. 案例 numdigits.c：反复除以 10 计位数——0 也有一位，正是 do-while 的适用场景。

### 五、break 与 continue（15 分钟）
1. break：跳出最内层循环/switch；素数判定的提前退出；交互式输入模式（立方程序，while(1)+break）；嵌套时只跳一层。立方程序为==弹性内容==，时间不够可快讲。
2. continue：跳到循环体末尾之前（本轮跳过）；与 break 的对比表；改写示例（if (i != 0) 等价写法）。

### 六、课堂小测（5 分钟）
题目见 5-1 课件「课堂小测」页，参考答案：
1. do-while 先执行后判定，循环体至少执行一次；while 可能一次都不执行；
2. break 跳出循环；continue 跳到本轮循环体末尾，直接进入下一轮（只能用于循环）；
3. max 不能用 0 初始化——用第一个输入的数作初值（全负数时才正确）。

### 七、小结与作业（10 分钟）
1. 小结：while = 先判定后执行；do-while = 至少一次；break/continue 控制跳出与跳过。
2. 作业：OJ 周练；写程序：输入 n 打印 1~n 的平方（while 版）；用 while 求 1+2+...+n（注意 sum 初值为 0、循环变量要递增）；用 while 重写猜数字；预习：for 语句（周三）。

## 第5周周三：循环结构（下）—— for 与算法案例（100 分钟）

### 二、for 语句（30 分钟）
1. for 形式（表达式1/2/3 职责）与倒计数示例；与 while 的等价转换。
2. i-- 与 --i 在表达式3中等价（通过等价 while 理解）；表达式1/3 只看副作用。
3. 常见惯用法四式（0..n-1、1..n、n-1..0、n..1）与三种常见错误（方向写反、== 、差一）。

### 四、常量数组与现场挑战（25 分钟，先问题后代码两页式，难度递进）

3. 回文数：数字拆进数组、首尾对称比较（len-1-i 下标推演；发现不对称提前 return；只比到 len/2）。

### 五、sizeof 与变长数组（15 分钟）
1. sizeof(a)/sizeof(a[0]) 求元素个数——改数组长度不用改循环。
2. 变长数组（C99 简讲）：长度可以是变量。

### 六、课堂小测（5 分钟）
题目见 6-1 课件「课堂小测」页，参考答案：

## 第7周周三：查找与课堂编码（100 分钟）

课件 7-2-searching。

### 一、回顾与导入（10 分钟）
1. 回顾三种排序；抛问题：排好序了，怎么快速找到某个元素？——引出查找。

### 二、顺序查找（20 分钟）
1. 逐个比较、找到即停：for + break；`i < n` 说明提前退出（找到）、`i == n` 说明正常结束——与第 5 周素数判断同款写法。
2. 适合无序数据；平均 n/2 次、最坏 n 次。

### 三、二分查找（25 分钟）
1. 前提：数组有序。每次和中间元素比较，砍掉一半（演示图 + 代码）。
2. 现场演示对比：100 万个元素最多约 20 次（log2(10^6) ≈ 20）。
3. 循环条件 low <= high 的原因：low == high 时区间还剩一个元素待查。

### 四、课堂编码（30 分钟）
1. 输入 10 个数，用选择排序从小到大排好并输出。
2. 在上一题的有序数组上，输入一个数，用二分查找输出下标；找不到输出 not found。
3. 挑战：统计该数在有序数组中出现了几次（找到位置后向左右扫描计数）。

### 五、课堂小测与小结（15 分钟）
题目见 7-2 课件「课堂小测」页，参考答案：
1. 最坏 n 次；平均 n/2 次；
2. 数组必须已排好序；
3. 约 20 次（log2(10^6) ≈ 20）；
4. `/` 优先级高于 `+`——`low + high / 2` 变成 `low + (high/2)`，区间砍不对；应写 `(low + high) / 2`。
