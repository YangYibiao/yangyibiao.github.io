  4. 递归构建子树

直到：

  • 节点足够纯净
  • 达到停止条件

K-Means中的“K”是什么？

K：

表示簇（Cluster）的数量。

例如：

K-Means中的Means是什么？

Means：

表示均值（中心点）。

每个簇：

都有一个中心。

簇1中心
簇2中心
簇3中心

算法不断调整中心位置。

K-Means工作流程 

随机初始化K个中心
        ↓
计算距离
        ↓
分配样本
        ↓
更新中心
        ↓
重复迭代

直到中心不再变化。

最常见：

d(x,y)=∑(xi−yi)2d(x,y)=\sqrt{\sum(x_i-y_i)^2}d(x,y)=∑(xi​−yi​)2​

直观理解：

两点之间直线距离。

(9,8)

K=2

很自然形成：

含义：

如何选择K？

核心问题：

K应该是多少？

常用方法：

  • 肘部法（Elbow）
  • 轮廓系数（Silhouette）

肘部法

绘制：

K
↓
误差平方和

随着K增加：

误差下降。

出现明显拐点：

即较优K值。

轮廓系数

衡量：

簇内紧密度
+
簇间分离度

取值：

[-1,1]

越接近1越好。

什么是关联规则？

形式：

A → B

例如：

牛奶 → 面包

含义：

购买牛奶的人

往往也购买面包。

Apriori核心思想

频繁项集：

经常同时出现的商品组合。

例如：

{牛奶,面包}

出现很多次。

Apriori的关键假设

著名性质：

频繁项集的所有子集一定频繁。

例如：

如果：

{A,B,C}

频繁。

那么：

{A,B}
{A,C}
{B,C}

也必须频繁。

支持度（Support）

定义：

Support(A)=A出现次数总交易数Support(A)= \frac{A出现次数}{总交易数}Support(A)=总交易数A出现次数​

例如：

100笔订单。

20笔包含牛奶。

支持度：

20%

置信度（Confidence）

定义：

Confidence(A→B)=Support(A,B)Support(A)Confidence(A→B) = \frac{Support(A,B)} {Support(A)}Confidence(A→B)=Support(A)Support(A,B)​

表示：

购买A后购买B的概率。

提升度（Lift）

定义：

Lift=Confidence(A→B)Support(B)Lift= \frac{Confidence(A→B)} {Support(B)}Lift=Support(B)Confidence(A→B)​

解释：

大于1：

正相关。

小于1：

负相关。

      ↓
...

GaussianNB代码实践 

from sklearn.datasets import make_classification
from sklearn.naive_bayes import GaussianNB

X, y = make_classification(
    n_samples=2000,
    n_features=10,
    n_informative=6,
    random_state=42
)

model = GaussianNB()

model.fit(X, y)

模型预测 

pred = model.predict(
    X[:10]
)

print(pred)

输出：

[1 0 1 1 0 ...]

查看概率 

proba = model.predict_proba(
    X[:5]
)

print(proba)

输出：

[[0.1 0.9]
 [0.8 0.2]
 ...]

表示：

属于每个类别的概率。

模型评估 

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)

model.fit(X_train, y_train)

print(
    model.score(X_test,y_test)
)

手算推演开始

现在不使用代码。

亲手计算一次贝叶斯分类。

已知条件

100封邮件：

垃圾邮件：40封

正常邮件：60封

因此：

P(垃圾)=0.4

P(正常)=0.6

特征统计

词语：

中奖

出现情况：

垃圾邮件：

32/40

正常邮件：

6/60

因此：

P(中奖|垃圾)=0.8

P(中奖|正常)=0.1

问题

收到新邮件：

包含“中奖”

求：

P(垃圾|中奖)

第一步

计算：

P(中奖)

根据全概率公式：

P(中奖)
=
0.8×0.4
+
0.1×0.6

结果：

0.38

第二步

代入贝叶斯公式：

P(垃圾|中奖)

=
0.8×0.4
/
0.38

计算结果 

0.842

即：

84.2%

因此：

该邮件大概率是垃圾邮件。

思考题

如果：

P(垃圾)=1%

其他条件不变。

结果会发生什么？

思考题参考答案

后验概率会显著下降。

原因：

先验概率极低

即使证据很强：

最终概率也未必高。

这正是贝叶斯思想的精髓。

第四部分：孤立森林

Isolation Forest

提出时间：

2008

已经成为工业界经典异常检测算法。

一个有趣的问题

假设：

房间里有100个人。

其中：

99个人站在一起。

1个人站在角落。

问题：

谁最容易被发现？

答案：

角落那个人

孤立森林的核心思想

核心观点：

异常点更容易被孤立出来。

正常点：

聚集在一起

异常点：

远离群体

因此：

更容易被随机切分出来。

随机切分示意 

正常点：

●●●●●●●●●

异常点：

          ▲

随机切分：

很快就能单独圈出▲

为什么叫“森林”？

因为：

不是一棵树。

而是：

很多随机树

每棵树：

随机选择：

  • 特征
  • 切分点

最终综合结果。

孤立树构建过程 

随机选择特征
       ↓
随机选择切分点
       ↓
划分数据
       ↓
继续递归

直到：

样本被隔离。

路径长度

关键指标：

Path Length

含义：

一个样本被隔离前：

经过多少次切分。

异常点：

路径短

正常点：

路径长

异常得分

最终输出：

Anomaly Score

接近：

1

异常可能性高。

接近：

0

异常可能性低。

Isolation Forest代码实践

生成模拟数据：

import numpy as np

normal_data = np.random.randn(
    1000,
    2
)

outliers = np.random.uniform(
    low=8,
    high=10,
    size=(20,2)
)

X = np.vstack(
    [normal_data,outliers]
)

训练模型 

from sklearn.ensemble import IsolationForest

model = IsolationForest(
    contamination=0.02,
    random_state=42
)

model.fit(X)

预测异常 

pred = model.predict(X)

print(
    np.unique(pred,
              return_counts=True)
)

输出：

-1 异常

 1 正常

查看异常得分 

scores = model.score_samples(X)

print(
    scores[:10]
)

结果：

值越小
越异常
