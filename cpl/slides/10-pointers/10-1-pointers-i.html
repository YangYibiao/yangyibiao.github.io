内存地址: 每个字节一个编号

内存按字节划分, 每个字节存 8 位.

每个字节一个编号, 这个编号就是地址.

n 个字节 → n 个地址 (0 ~ n-1)

每个字节的地址唯一, 相邻字节的地址差 1.

地址是位置, 不是内容.

实际地址常写成十六进制, 如 0x1000.

一句话: 地址 = 字节的编号 (门牌号); 编号与字节一一对应.

变量住在内存里: 地址

变量 i 也住在这条内存街上, 占了 4 个连续字节, 从 0x1000 开始.

i 的值 42
i 的地址 0x1000
i 占的字节 0x1000 ~ 0x1003

一句话: 变量地址 = 第一个字节的地址; 0x1000~0x1003 是 i 的 4 个字节, 但 &i 只取 0x1000.

x86 小端 42 = 0x0000002A
低地址 2A   00   00   00 高地址

2A 00 00 00 按地址从低到高拼成 0x0000002A = 42, 不能把字节顺序反过来当成 0x2A000000.

指针变量也是变量: 它存的是地址

int i = 42; int *p = &i; 之后, 内存里有两个变量:

  • p 自己也在内存里, 住在 0x2000

  • p 的值是 0x1000——也就是 i 的地址

  • 所以 &i 和 p 都是 0x1000; &p 是 0x2000; *p 是 42

一句话: 指针变量 = 普通变量, 只是它的值恰好是一个地址.

先看一个完整的例子: 指针能做什么
代码
int i = 42;
int *p = &i;          /* 声明 p, 让它指向 i */

printf("%d\n", *p);   /* 读 *p: 输出 42 */
*p = 7;               /* 写 *p: 把 i 改成 7 */
printf("%d\n", i);    /* 输出 7 */
① 声明
int *p = &i;
② 读
*p → 42
③ 写
*p = 7 → i = 7
指针能做什么: 通过地址间接读写变量; 让多个指针指向同一对象 (q = p); 让函数修改实参、遍历数组 (后面细讲).
声明与初始化: 让 p 指向 i
声明
int *p;        /* p 存 int 对象的地址 */
double *q;     /* 只能指向 double */
char *r;       /* 只能指向 char */

  • 类型要匹配: int * 只能指向 int 对象

  • 可以和其他变量一起声明: int i, *p;

初始化: 把地址赋给 p
int i = 42;
int *p = &i;   /* 声明时初始化 */
int i = 42, *p;
p = &i;        /* 先声明, 后赋值 */

  • &i 得到 i 的地址; 赋值后 p 指向 i

  • 声明只给 p 留了空间; 没有初始化就使用, 行为未定义

通过指针访问: *p 就是 i
代码
int i = 42, *p = &i;

printf("%d\n", *p);   /* 读 *p: 输出 42 */
*p = 7;               /* 写 *p: i 变成 7 */
printf("%d\n", i);    /* 输出 7 */

*p 是 i 的别名: 读 *p 就是读 i, 写 *p 就是写 i.

& 取地址, * 解引用; 两者互为逆运算: *&i 就是 i.

  • p 必须已经指向一个有效对象; 未初始化的指针不能解引用

  • 下一张先看打印地址的程序, 后面的示例逐行演示 *p 如何改变 i

把地址打出来 
#include <stdio.h>

int main(void)
{
  int i = 42;
  int *p = &i;

  printf("&i = %p\n", (void *)&i);
  printf(" p = %p\n", (void *)p);
  printf("&p = %p\n", (void *)&p);
  printf("*p = %d\n", *p);
  return 0;
}

运行结果 (地址每次运行都不同):

&i = 0x7ffd5a3c1c
 p = 0x7ffd5a3c1c
&p = 0x7ffd5a3c20
*p = 42

  • &i 与 p 相同: p 里存的就是 i 的地址

  • &p 不同: p 自己也有地址, 它住在 0x7ffd5a3c20

  • *p 等于 i: 顺着 p 里的地址找到 i

  • %p 用来打印地址; 地址每次运行可能不同, 不要硬编码比较

间接寻址运算符 * (上): 完整例子
完整代码 · deref.c
#include <stdio.h>

int main(void)
{
    int i = 1;
    int *p = &i;                         /* p 指向 i */

    printf("i = %d, *p = %d\n", i, *p);  /* 1 1 */
    *p = 2;                              /* 通过 p 改 i */
    printf("i = %d, *p = %d\n", i, *p);  /* 2 2 */
    return 0;
}
⚡ 在 VS Code 中打开 deref.c
运行结果
i = 1, *p = 1
i = 2, *p = 2

一句话: *p 与 i 是同一块内存; 读 *p 就是读 i, 写 *p = 2 就是写 i.

以上结果的前提是 p 已经指向 i. 如果 p 没有初始化, *p 会怎样? 下一张看反例.

间接寻址运算符 * (下): 未初始化指针
反例: p 没有初始化
int *p;                          /* 未初始化: p 里是垃圾值 */
printf("p  = %p\n", (void *)p);  /* 看看 p 里到底是什么 */
printf("*p = %d\n", *p);         /* 未定义行为 */
*p = 1;                          /* 更危险: 可能改写未知内存 */
某次运行的实际输出:
p = 0x1f1b34100
*p = -239910720
Bus error (core dumped)

实际值每次/每台机器可能不同, 也可能是 Segmentation fault.

  • 崩溃 (段错误/总线错误) — 这其实是"最好"的结果

  • 读到/写入垃圾值 — 程序继续跑, 但结果不可信

  • 悄悄改坏其他变量 — 最危险, 很难发现

正确做法: 先 p = &i;, 确认 p 指向有效对象, 再使用 *p; 声明后未初始化的指针不能解引用.

指针赋值: 多个指针指向同一块内存
代码
int i = 1, *p, *q;

p = &i;        /* p 指向 i */
q = p;         /* q 也指向 i: 复制地址 */
*p = 1;        /* i = 1 */
*q = 2;        /* i = 2 */
printf("%d %d %d\n", i, *p, *q);  /* 2 2 2 */
语句 p q i
p = &i&i?1
q = p&i&i1
*q = 2&i&i2
然后? q = p 后, p 和 q 指向同一块内存; *q = 2 改的就是 i, 通过 p 看也是 2.

  • q = p 复制的是地址, 不是 i 的值

  • 之后 p、q 指向同一块内存; *p、*q 都是 i

  • 任意多个指针都可以指向同一个对象; 改一个, 其他都能看到

指针赋值 (下): q = p 与 *q = *p 的区别
完整代码 · assign-compare.c
#include <stdio.h>

int main(void)
{
    int i = 1, j = 2;
    int *p = &i, *q = &j;

    /* ① q = p: 复制地址 */
    q = p;          /* q 改指向 i, 不再指向 j */
    *q = 3;         /* 改的是 i */
    printf("q = p 后:   i=%d j=%d *p=%d *q=%d\n", i, j, *p, *q);

    /* ② *q = *p: 复制值 */
    p = &i; q = &j; i = 1; j = 2;   /* 重置 */
    *q = *p;        /* 把 i 的值复制给 j */
    printf("*q = *p 后: i=%d j=%d *p=%d *q=%d\n", i, j, *p, *q);

    return 0;
}
⚡ 在 VS Code 中打开 assign-compare.c
运行结果
q = p 后:   i=3 j=2 *p=3 *q=3
*q = *p 后: i=1 j=1 *p=1 *q=1
q = p — 复制地址

q 改指向 i; p、q 指向同一块内存; 改 *q 就是改 i; j 不变.

*q = *p — 复制值

q 仍指向 j; 把 i 的值写进 j; i、j 是两块不同的内存.

一句话: q = p 改的是 q 的指向; *q = *p 改的是 j 的值.

任务: 参考代码与要点 
#include <stdio.h>

int main(void)
{
  int a = 3;
  int *p = &a;                 /* p 指向 a */

  printf("a = %d, &a = %p, p = %p, *p = %d\n",
         a, (void *)&a, (void *)p, *p);

  *p = 7;                      /* 通过 p 改写 a */
  printf("改写 *p 之后: a = %d, *p = %d\n", a, *p);
  return 0;
}

  • p = &a: p 里存的是 a 的地址; 所以 &a 与 p 打印结果相同

  • *p 是 a 的别名: 读 *p 就是读 a, 写 *p = 7 就是写 a

  • %p 打印指针 (地址); 每次运行的地址不同, 不要硬编码比较

  • 指针类型要匹配: int *p 只能指向 int 对象
