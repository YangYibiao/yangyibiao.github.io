# 第10周讲义（两次课 × 100 分钟）

课件：10-1-pointers（周二，18 页）、10-2-pointer-arrays（周三，20 页）。
素材来源：slides_2022 的 11-Pointers / 12-PointersAndArrays（King 教材全文译文）。

## 第10周周二：指针基础（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾第 9 周的数组作参数："函数能改原数组，第 10 周解释为什么"——今天揭晓。
2. 抛出问题：变量住在内存的什么位置？能不能"按地址"访问它？

### 二、指针变量（25 分钟）
1. 地址的概念：内存按字节编号，变量的地址 = 它的首字节编号（配合图示）。
2. 指针变量：专门存放地址的变量；`int *p;` 中 p 的类型是"指向 int 的指针"。
3. 声明指针变量：`int *p;` / 多个声明的陷阱（`int *p, q;` 只有 p 是指针）。

### 三、& 和 * 两个运算符（25 分钟）
1. `&` 取地址：`p = &x;`；呼应 scanf 里的 `&`（终于知道为什么了）。
2. `*` 间接寻址：`*p` 等价于 p 指向的那个变量；可读可写（`*p = 10;`）。
3. 互逆关系：`*&x` 等价于 x；`&*p` 等价于 p。

### 四、指针赋值与传址调用（25 分钟）
1. 指针赋值：`q = p` 让两个指针指向同一对象；`*q = *p` 是复制值不是复制指针。
2. **传址调用**：`swap(int *a, int *b)`——为什么值传递改不了实参、指针能改。
3. decompose 的故事（King：第 9 章失败的函数用指针救回来）。

### 五、案例与 const（10 分钟）
1. 程序: 查找数组中最大和最小的元素（用指针参数带回两个结果）。
2. const 保护参数：`const int *p` 表示"只读"，防止函数误改。

### 六、课堂小测（5 分钟）
题目见 10-1 课件「课堂小测」页，参考答案：
1. 存的是地址（某变量的首字节编号）；p 的类型是 `int *`（指向 int 的指针）；
2. `&x` 取 x 的地址；`*p` 访问 p 指向的对象；是互逆运算（`*&x` = x）；
3. `*p = 10` 改的是 p 指向的那个变量的值；`p = &x` 改的是 p 本身（让它指向 x）；
4. 因为 C 是值传递——传值改不了实参；传地址后函数可以通过 `*a` 改到调用者的变量（`*a` 与 `*b` 交换）。

## 第10周周三：指针与数组（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾 &/*；
2. 抛问题：数组名是什么？能不能把数组名赋给指针？

### 二、指针的算术运算（25 分钟）
1. 指针 + 整数：`p + 1` 指向"下一个元素"（地址加的是元素大小，不是 1 字节）。
2. 指针 - 整数；两个指针相减 = 元素个数差（不是字节差）。
3. 比较指针：`p < q` 判断先后位置。

### 三、用指针处理数组（25 分钟）
1. `for (p = a; p < a + n; p++)` 的遍历法。
2. `*p++` 的含意（先取值再移动）与四行对照表；
3. 数组名作为指针：`a` 等价于 `&a[0]`；`a[i]` 等价于 `*(a + i)`。
4. 数列反向改进版（用两个指针相向而行）。

### 四、数组型实际参数（改进版）（25 分钟）
1. 形参 `int a[]` 与 `int *a` 完全等价——**这就是"函数能改原数组"的原因**（传的是地址）。
2. 数组参数的四条后果：能改元素、sizeof 失效、长度必须另传、可以传数组的一部分。
3. 多维数组的元素/行/列与指针（选讲其中元素与行）。

### 五、课堂小测（5 分钟）
题目见 10-2 课件「课堂小测」页，参考答案：
1. 指向下一个 int 元素；地址增加 sizeof(int) = 4 字节；
2. 元素个数差（指针相减自动除以元素大小）；
3. 等价于 `*(p++)`：先取 p 当前指向的值，再把 p 移向下一个元素；
4. 数组名等价于首元素地址，`a == &a[0]` 成立（但不能给 a 赋值——它不是左值）。

### 六、小结与作业（10 分钟）
1. 小结：指针 = 地址；& 与 * 互逆；指针算术按元素走；数组名是指针。
2. 作业：OJ 周练；写 `void min_max(int a[], int n, int *min, int *max)`；用指针重写数列反向；预习：字符串（第11周）。
