# 第8-9周讲义（4 次课 × 100 分钟）

课件：8-1-functions-i（第8周周二）、8-2-functions-ii（第8周周三）、9-1-array-params（第9周周二）、9-2-recursion（第9周周三）。

## 第8周周二：函数（I）—— 定义、调用与参数传递（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾第 7 周排序：三种排序的循环都写在 main 里，想排两组数据就得抄两遍。
2. 导入案例（新增）：排列组合计算器 P(m,n)、C(m,n)——现场演示"不用函数"版：m!、n!、(m-n)! 三段几乎一样的循环，只有上界不同；提问"这段代码有什么问题"（重复、难改、难扩展）。
3. 函数版对比：factorial 写一遍、调用三遍，main 只剩读入→计算→输出。
4. 软件设计原则页：复用、模块化、封装——用刚才的例子收束。

### 二、函数的定义与调用（30 分钟）
1. 函数概念与一般形式：返回类型 函数名(参数) { 语句 }；double average(double a, double b)。
2. 计算平均值案例：avg.c 从 main 里"抽出" average 函数，对照改写前后。
3. 显示倒计时、双关语改进版：void 函数与带参函数。
4. 函数调用的执行流程：跳进函数、执行、返回调用点。

### 三、函数声明（15 分钟）
1. 为什么需要声明（编译器从上往下读）；函数原型形式。
2. 声明与定义的顺序问题：先声明后使用。

### 四、参数传递（20 分钟）
1. 实参/形参的概念；按值传递（形参是实参的副本——第10周指针再讲传址）。
2. 演示页（新增）：swap 为什么不生效——传值调用只交换副本，函数"没效果"；留悬念：第 10 周用 swap(&x, &y) 解决。
3. 实际参数的转换：类型不匹配时按赋值规则转换。

### 五、return 与程序终止（10 分钟）
1. return 语句的作用与形式；void 函数中 return; 的用法。
2. return 0 与 exit(0) 的区别（exit 在任意位置立即终止，需 stdlib.h）。

### 六、课堂小测（5 分钟）
题目见 8-1 课件「课堂小测」页，参考答案：
1. 函数首部（返回类型+函数名+参数表）与函数体；return 把值交还给调用者；
2. 声明（或定义在前）；返回类型 函数名(参数类型表);；
3. 按值传递；形参是实参的副本，改形参不影响实参；
4. void 表示不返回任何值；exit(0) 在任意位置立即终止程序（需 <stdlib.h>），return 只结束当前函数。

### 七、小结与作业（10 分钟）
1. 小结：函数 = 带名字的代码块；定义/声明/调用三件套；按值传递。
2. 作业：OJ 周练；把第7周的"选择排序"程序改写为函数版；预习：函数编码与栈（周三）。

## 第9周周二：函数进阶—— 数组作参数、函数化改造与作用域（100 分钟）

课件 9-1-array-params（数组作参数 + 作用域三页，原 7-2 的预处理部分已并入第 14 周多文件课）。

### 一、回顾与导入（10 分钟）
1. 回顾函数与栈（第8周）；抛问题：函数能处理数组吗？第 7 周的排序怎么封装成函数？

### 二、函数化改造：排序封装（10 分钟）
1. 把第 7 周 main 版选择排序装进 `void sort(int a[], int n)`——同一段逻辑，换数组调用。
2. 点题：函数化改造 = 把重复的逻辑抽出来封装——本周核心任务。

### 三、一维数组作参数（15 分钟）
1. 三条规则：形参 `int a[]`（长度可不写）、长度必须单独传、调用只写数组名不加 `[]`。
2. 函数里改数组 = 改原数组（排序就是这样工作的）；原因第 10 周指针章揭晓。

### 四、二维数组作参数（15 分钟）
1. **只能省略第一维**，列数必须写在形参里：`int sum_matrix(int a[][4], int rows)`。
2. 为什么：编译器要知道"一行有多长"才能算出 `a[i][j]` 的地址。

### 五、案例（15 分钟）
1. 矩阵转置函数化：`transpose(int a[][4], int b[][3], int rows)`——两个形参各自的列数（第 6 周转置逻辑的函数版）。
2. 成绩统计函数化：`row_sums(int scores[][3], int n, int sums[])`——二维进、一维出。

### 六、作用域与生命期（15 分钟）
1. 块作用域（局部变量、形参）与文件作用域（全局变量）；内层遮蔽外层；全局变量少用。
2. 动态变量（默认）与 static 局部变量（只初始化一次、"带记忆"）。
3. 演示页：局部变量的"垃圾值"——不初始化就用，读到内存残留；教训：先初始化再用。

### 七、课堂编码（15 分钟）
三个函数现场写：sum_matrix / col_average / is_symmetric；提示"先想清楚形参的列数写多少"。

### 八、课堂小测与小结（5 分钟）
题目见 9-1 课件「课堂小测」页，参考答案：
1. 形参 `int a[]`（长度不写）、长度单独传、调用只写数组名；
2. 不能——列数不匹配（4 ≠ 5），编译或行为出错；
3. a 是 3×4，转置后 b 是 4×3，所以 b 的列数是 3（即 a 的行数）；
4. static 局部变量只初始化一次、函数返回后保留原值（"带记忆"）；普通局部变量每次调用重新创建。
作业：OJ 周练；把第7周的插入排序封装成函数；预习：递归（周三）。

## 第9周周三：递归函数（100 分钟）

课件 9-2-recursion（含新增「递归排序: 快速排序」4 页——分治法、快排、split、空位法，为==弹性内容==，时间不够可压缩只讲分治法+快排两页）。

### 一、回顾与导入（10 分钟）
1. 回顾函数与栈（第8周）；抛问题：函数能不能调用自己？——引出递归。

### 二、递归入门（25 分钟）
1. 递归概念：函数直接或间接自己调用自己。
2. 递归的定义（n! 例子）：基准情形 + 递归情形。
3. 阶乘递归实现与执行过程：递推/回归、层层压栈（呼应第8周函数栈）；递归深度与栈溢出。

### 三、经典案例（30 分钟）
1. Fibonacci：两个递归调用；指出重复计算代价（f(2) 被算多遍）——第 5 周习题课的循环版对比。
2. 递归 gcd：与第5周循环版对比——递归更贴近数学定义。
3. Hanoi 塔：问题 → 三步思路 → 代码；强调"把问题交给递归"（64 盘需 2^64-1 步）。

### 四、递归排序：快速排序（15 分钟，弹性）
1. 分治法：分 → 治 → 合；生活例子（整理试卷）。
2. 快排：基准 + 划分 + 对左右递归；第 7 周三种排序都是 O(n²)，快排平均 O(n log n)——悬念兑现。
3. split 划分函数（无指针版）+ "空位法"一趟演示；完整程序 code/qsort-split.c（在 2-if-for-array/code/ 下）。

### 五、常见错误与课堂编码（15 分钟）
1. 两个常见错误：缺基准情形、问题不缩小。
2. 现场编码：递归求和、递归求幂、printd（整数打印）。

### 六、课堂小测与小结（5 分钟）
题目见 9-2 课件「课堂小测」页，参考答案：
1. 基准情形（终止条件）+ 递归情形（规模缩小后调用自身）；
2. 5 层（f(5) 到 f(1)，逐层压栈）；
3. fib(2) 被算 3 次（fib(5)→fib(3)+fib(4) 两路都算）——朴素递归的重复计算代价；
4. 递归适合"自我相似"的问题（树形结构、分治），循环适合简单重复；递归更接近数学定义但开销更大。
