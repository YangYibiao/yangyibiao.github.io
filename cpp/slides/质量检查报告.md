## 七、已知限制

1. **浏览器差异**：reveal.js 4.6 的 `convex` 过渡在部分旧浏览器上可能略有差异；功能不受影响。
2. **字体回退**：主题 CSS 引用 Google Fonts 的 Lato；离线时回退到系统 sans-serif，版式不受影响。
3. **Ranges 支持**：第 13、16 周的 Ranges 示例需要 C++20 标准库（GCC 10+ / Clang 13+ 搭配 libc++）；旧环境可改用页面中给出的 `copy_if` / `transform` 版本。
4. **并发示例**：线程数量、调度与性能数据因机器而异；课件中的时间仅用于说明趋势，不是基准。
5. **代码片段**：为控制单页信息密度，部分示例跨页展示；完整可运行版本在 `code/` 中，其余片段按“教学片段”理解。
6. **未提交 Git**：本次仅生成文件，未执行 `git add/commit`；是否入库由课程负责人决定。
