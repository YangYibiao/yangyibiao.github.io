# 第2-3周讲义（4 次课 × 100 分钟）

课件：2-1-variables（第2周周二）、2-2-io（第2周周三）、3-1-operators（第3周周二）、3-2-conversion（第3周周三），均为连续课件，从头翻到尾。

## 第2周周二：数据类型深化（100 分钟）

（周三已讲过变量与基本类型入门，本节深化并留出课堂编码时间。）

### 一、回顾与导入（10 分钟）
1. 回顾周三：变量/类型/声明/初始化/scanf；检查作业（名片程序、温度转换改编）。
2. 抛问题：int 能存多大的数？怎么让变量只存正数？——引出修饰符与取值范围。

### 二、类型修饰符与取值范围（25 分钟）
1. 修饰符表（课件页）：short/long、signed/unsigned；位数 short ≤ int ≤ long；sizeof 查看字节数。
2. 「整型的取值范围与溢出」页（2-1 课件）：int 通常 32 位；INT_MAX = 2^31-1 ≈ 21 亿；**现场演示 INT_MAX+1 溢出"绕回"成负数**（C 不报错）；limits.h；sizeof 呼应修饰符页。
2.4 「整数在内存里长什么样」页（2-1 课件，选讲/了解）：32 位图示、负数用补码、有符号 vs 无符号的范围、溢出"绕回"的真相；==一句话带过，不展开==。
2.5 「浮点数在内存里长什么样」页（2-1 课件，选讲/了解）：IEEE 754 的三个部分（符号/指数/尾数）、0.1 的二进制截断示意；==一句话带过即可，不展开位级细节==——目标是让学生知道"浮点是近似存储、别用 == 比较"有据可依。
3. 「字符与 ASCII」页（2-1 课件）：编码即整数（大小写差 32）；同一变量 %c 打字符 / %d 打编码；`ch - 32`、`'9'-'0'` 字符转数字；toupper/tolower；ASCII 表配图。

### 三、赋值细节（15 分钟）
1. 先声明后使用（错误示例）；float 常量加 f 后缀；double 不加。
2. 混合类型赋值（double→int 截断）——第 3 周类型转换的铺垫。

### 四、常量与符号常量（15 分钟）
1. #define（预处理、行末无分号）与 const（只读变量）。
2. 为什么用符号常量：可读性 + 改一处而不改四处。

### 五、案例与课堂编码（25 分钟）
1. Circle：半径→周长与面积（%.2f）；现场改成 #define PI 版本，对比"改一处 vs 改四处"。
2. Sphere：%-15.4f 左对齐与宽度（格式细节的预告）。
3. 课堂编码：学生现场把 Circle 改成输入半径的版本（scanf）。

### 六、课堂小测（5 分钟）
题目见 2-1 课件「课堂小测」页，参考答案：
1. unsigned 只表示 0 与正数（范围更大）；sizeof；
2. #define 行末不加分号；const 是声明要加分号；
3. limits.h；int 能表示的最大值；
4. 可读性好、便于修改（改一处）。

### 七、小结与作业（5 分钟）
1. 小结：修饰符决定取值范围与符号；符号常量让程序易读易改。
2. 作业：OJ 周练；把 Sphere 改成输入半径版并用 #define PI；预习：格式化输入输出（周三）。

## 第2周周三：格式化输入输出（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾 printf 基本用法（%d/%f），引出格式控制的细节。
2. 抛问题：想让数字右对齐、控制小数位、打印表格怎么办？

### 二、printf 与转换说明（30 分钟）
1. 格式字符串 = 普通字符 + 转换说明；%d/%f/%c/%s。
2. 转换说明 %m.pX：最小字段宽度 m（右对齐/左对齐 %-m）；精度 p（%d 补零、%e/%f/%g 小数位）。
3. 常见错误：转换说明数量不匹配、类型不匹配（编译器不检查）。
4. 演示 tprintf 程序，逐列对照输出。

### 三、转义序列（8 分钟）
\n、\t、\a、\b；打印引号 \" 和反斜杠 \\。

### 四、scanf（30 分钟）
1. scanf 基本用法与 &；格式串通常只含转换说明。
2. 工作原理：跳过空白、读到不属于该类型的字符停止并"放回"、失败立即返回。
3. 缓冲区演示（新增页）：多次 scanf 共享一条输入字符流，每次从上次位置接着读；演示一次输入 `10 20↵`、两个 scanf 依次消费 10 和 20、中间 printf 立即打印。试一试的答案：第一次只输入 `10↵` 就回车，程序卡住——第二个 scanf 跳过空白后缓冲区里没有整数，等待继续输入。
4. 格式字符串中的普通字符（"%d/%d" 要求输入 5/96）；scanf 与 printf 的三个混淆点（printf 加 &、scanf 加逗号、scanf 末尾 \n 会挂起）。
5. scanf 读字符串（新增页）：char s[100]（不加 &、开得足够大、结尾 '\0'）；%s 遇空白就停只读一个"单词"；%[^\n] 读带空格的一整行；getchar 先吃掉上一行遗留换行的坑（呼应前一页）；printf 用 %s 输出。
6. getchar / putchar（新增页）：字符处理的常用方式。

### 五、综合案例：分数相加（7 分钟）
addfrac.c：scanf("%d/%d") 读分数、通分相加、printf 输出。

### 六、课堂小测（5 分钟）
题目见 2-2 课件「课堂小测」页，参考答案：
1. `-` 左对齐、`8` 最小字段宽度、`.3` 小数点后 3 位；
2. \" 和 \\；
3. 输入如 `5/6`（两个整数中间必须是 `/`）；
4. int（比 char 宽，可以表示 EOF）；读写字符效率高于 scanf，适合字符处理程序。

### 七、小结与作业（10 分钟）
1. 小结：printf 控制"怎么显示"，scanf 控制"怎么读入"；格式串要自己检查匹配。
2. 作业：OJ 周练；写程序：输入两个分数输出和（约分版选做）；预习：运算符与表达式。

## 第3周周二：运算符、表达式与数学库（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾变量与 IO；抛出问题：1/2 为什么等于 0？——引出运算符。

### 二、算术运算符（18 分钟）
1. 一元（+/-）与二元（+ - * / %）；int/float 混合运算的规则。
2. / 与 % 的坑：整数除法截断、% 要求整数、除零未定义、负数行为（C99 向零截断）。
3. 由实现定义的行为：C 强调效率，不指定部分行为——别依赖。

### 三、优先级与结合性（20 分钟）
1. 优先级：一元 > * / % > 二元 + -；用 i + j * k 等例子。
2. 结合性：左结合（二元算术）、右结合（一元）；-+i 的例子。
3. 演示页（新增）：9 / 4 * 4 = 8 而 9 * 4 / 4 = 9——同样数字顺序不同结果不同；根因是整数除法截断 + 左结合；强调拿不准就加括号。
4. 动手算一算（新增两页）：8 道心算题先让学生自己算、再翻页对答案——覆盖优先级（% 高于 + -）、结合性（同级长链）、截断陷阱三连（-10/3 向零、括号救不了 14/4、中间截断 9-3/2+1）、一元负号（-5 - -3）。

### 四、数学库函数（10 分钟）
1. 函数表页：+ - * / % 不够用（开方、幂、三角）→ 数学库函数；#include <math.h>，编译可能需 -lm（CLion 一般不用管）；7 函数表（abs/fabs/sqrt/pow/exp/log/log10/三角，x 为弧度）；返回值是 double，打印用 %f。
2. 使用示例页（新增一页）：现场演示 sqrt/pow/fabs + sqrt(2)、pow(2, 0.5)（0.5 次方 = 开方），对照运行结果；函数调用是表达式、%.3f 控小数位。
3. 预告：本周作业用 sqrt/fabs 做 |a-b| 的平方根。

### 五、赋值与复合赋值（20 分钟）
1. 简单赋值 v = e：类型转换、赋值是运算符（i = j = k = 0，右结合）。
2. 复合赋值 += 等 10 个：i *= j + k ≠ i = i * j + k；i =+ j 是坑。

### 六、自增自减（10 分钟）
++i / i++ 的区别（先增后用 / 先用后增），-- 同理；多个 ++ 混用难读，建议分行写。

### 七、案例：UPC 校验位（7 分钟）
条形码结构 → 校验位计算流程 → 手算示例 → upc.c（%1d 逐个读数字）。

### 八、课堂小测（5 分钟）
题目见 3-1 课件「课堂小测」页，参考答案：
1. 0；1；0；
2. (-i) * (-j)；左结合，即 (i * j) / k；
3. i = i + 2；不等价（i *= j + k 是 i = i * (j + k)）；
4. i = 2，j = 1（先用旧值 1 再自增）；
5. #include <math.h>；gcc 可能需 -lm。

## 第3周周三：类型转换与未定义行为（100 分钟）

### 一、回顾与导入（10 分钟）
1. 回顾运算符优先级与数学库（周二新内容）；抛出问题：1.0 / 2 和 (float) 1 / 2 为什么是 0.5？——引出类型转换。

### 二、表达式求值与未定义行为（25 分钟）
1. 优先级总表 + 逐步加括号的示例。
2. 子表达式求值顺序未定义；(b = a + 2) - (a = 1)、i * i++ 的结果不确定。
3. 规避方法：拆成多条语句；避免同一表达式里既读又改同一变量。
4. 未定义行为的影响（不同编译器不同结果、崩溃等）——应避免。

### 三、副作用与左值（10 分钟）
1. 副作用 = 修改操作数（赋值、++/--）；嵌入式赋值难读。
2. 左值 = 存储对象；12 = i、i + j = 0 非法。

### 四、类型转换（15 分钟）
1. 隐式转换：赋值截断、运算提升（char/short → int，int + double → double）。
2. 演示页（新增）：a/b 用 %f 打印的坑——整数除法先截断后转换"来不及了"；%f 收到 int 是未定义行为（常见 0.000000 或乱码）；正确姿势 (double)a / b 或 a / 4.0。
3. 强制转换 (type)：优先级高，只作用紧邻操作数；(int)(3.9 + 1.1) 的括号。

### 五、编码实践（25 分钟）
1. mol.c（拆两页：先问题后代码）：第 1 页只给问题（6 克氧气的分子数、%.3e/%.5g 输出要求、提醒 6/32 整数除法坑），学生先自己写再翻页；第 2 页参考代码——mass * 1.0 提升为浮点、运行结果 1.129e+23 / 1.1288e+23。
2. 大学信息管理系统：char/char[]/%c/%.2d/toupper 综合运用（呼应第 2 周 scanf 读字符串页）。

### 六、课堂小测与小结（15 分钟）
题目见 3-2 课件「课堂小测」页，参考答案：
1. 3；(float) 1 / 2 = 0.5；
2. 3（截断，丢弃小数部分，可能无警告）；
3. 子表达式求值顺序未定义；避免在同一表达式中既读又改同一变量（拆成多条语句）。
作业：OJ 周练；用 math.h 写程序：输入两个整数输出 |a-b| 的平方根（数学库周二已讲）；预习：选择结构（第4周）。
