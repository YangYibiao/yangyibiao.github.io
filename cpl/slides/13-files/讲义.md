# 第14周讲义（2 次课 × 100 分钟）

课件：14-1-files（第14周周二，文件操作）、14-2-multi-file（第14周周三，预处理与多文件组织）。

## 第14周周二：文件操作（100 分钟）

1. 回顾与导入（10 分钟）：程序的数据一关机就没了——引出"长期保存"。
2. 流与文件（20 分钟）：流的概念、标准流与重定向、文本文件与二进制文件。
3. 打开与关闭（25 分钟）：fopen 模式表、"w" 模式清空演示（陷阱页）、关闭文件、从命令行获取文件名。
4. 读写（30 分钟）：字符 IO（复制文件案例）、行的 IO、块 IO；检测文件末尾与错误（EOF 与 feof 的坑）。
5. 文件定位与修改记录（10 分钟，弹性）。
6. 课堂小测与小结（5 分钟）。

课堂小测参考答案：
1. "r" 只读（文件必须存在）、"w" 清空后写（文件不存在则创建）；返回 FILE *，失败返回 NULL；
2. 要能表示 EOF（-1）——char 放不下，且 getc 读到的字符按 unsigned char 转 int；
3. feof 只在"读失败之后"才为真，提前判断会多循环一轮；应用输入函数返回值（EOF/NULL）判断结束；
4. fgets 一次读一行（保留 \n、自动补 \0），适合按行处理；fscanf 按格式解析、遇空白就停，适合格式化的数值读取。
作业：OJ 周练；写程序把一行行文字写入文件再读出打印；预习：多文件组织（周三）。

## 第14周周三：预处理与多文件组织（100 分钟）

1. 回顾与导入（10 分钟）：程序越来越大，一个文件放得下吗？——引出多文件。
2. 预处理（15 分钟）：预处理概念（# 命令 + gcc -E 眼见为实）、宏的文本替换与经典错误（= 和分号）。
3. 源文件与头文件（20 分钟）：为什么拆（清晰/单独编译/复用）、#include 指令、共享宏/类型/函数原型/变量声明（extern 类型必须一致）。
4. 带参宏（10 分钟）：MAX 加括号、MAX(i++, j) 副作用、宏名与括号间不能有空格。
5. 保护头文件（15 分钟）：重复包含问题（图）+ ifndef 写法（两页）。
6. 构建（20 分钟）：将程序划分为文件、makefile（命令行必须以 TAB 开头——错误示范页）、链接期间的错误。
7. 课堂小测与小结（10 分钟）。

课堂小测参考答案：
1. 头文件放共享的声明：函数原型、宏定义、类型定义；.c 放函数与变量的定义；
2. 防止同一头文件被多次包含导致重复定义编译错误（且以后加类型定义也不用担心）；
3. 命令行前面写成了 8 个空格——make 的每个命令行必须以 TAB 开头；
4. 修改实现不用改声明、调用处只需包含头文件；编译器能核对原型与定义一致。
作业：OJ 周练；把第 7 周排序程序拆成 sort.c + sort.h + main.c 并编译运行；预习：期末项目要求（第15周）。
