本讲目标

能够根据访问模式选择合适的容器，用算法 + Lambda 替代手写循环，并避开迭代器失效的坑。

STL 的三层结构
容器 containers

存储元素：vector、list、map、set ...

迭代器 iterators

指向元素、遍历容器，是容器与算法之间的桥梁。

算法 algorithms

sort、find、count、accumulate ... 通过迭代器操作元素。

算法不直接依赖容器，只依赖迭代器；因此 sort 可以用于 vector、deque、普通数组。

序列容器：vector / list / deque
容器 底层结构 随机访问 中间插入/删除 尾部插入 典型场景
vector 动态数组 O(1) O(n) 均摊 O(1) 默认选择、频繁遍历
list 双向链表 不支持 O(1) O(1) 频繁任意位置插入删除
deque 分段连续空间 O(1) O(n) O(1) 两端频繁增删 
std::vector<int> v{3, 1, 2};
v.push_back(4);
std::sort(v.begin(), v.end());
std::list<int> l{3, 1, 2};
l.push_front(0);
l.remove(1);   // 按值删除
默认选择

没有特殊理由时用 std::vector：缓存友好、随机访问快、内存连续。只有确实需要频繁中间插入/删除时才考虑 list。

关联容器：map / set / unordered_* 
std::map<int, Target> by_id;
by_id.emplace(1, Target(1, "main.o", 2));
by_id[2] = Target(2, "util.o", 4);

if (auto it = by_id.find(1); it != by_id.end()) {
    std::cout << it->second;
}

std::set<int> ids{3, 1, 2};   // 有序、去重
选择

  • map / set：有序，查找 O(log n)，基于平衡树

  • unordered_map / unordered_set：哈希，平均 O(1)，无序

  • multimap / multiset：允许重复关键字

注意 map::operator[] 在键不存在时会插入一个默认值；只查询时用 find 或 at。
容器适配器：stack / queue / priority_queue
适配器 操作 底层默认 典型场景
stack<T> push / pop / top deque<T> 后进先出
queue<T> push / pop / front deque<T> 先进先出
priority_queue<T> push / pop / top vector<T> + 堆 优先级调度 
std::stack<int> s;
s.push(1);
s.push(2);
int x = s.top();   // 2
s.pop();
std::priority_queue<Target> pq;
pq.push(Target(1, "低", 1));
pq.push(Target(2, "高", 5));
Target top = pq.top();   // 优先级最高
要求 priority_queue<Target> 需要 Target 支持 operator<；默认是最大堆（top 为最大元素）。
迭代器：抽象的指针 
std::vector<int> v{10, 20, 30};

for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << ' ';
}

auto it = std::find(v.begin(), v.end(), 20);
if (it != v.end()) {
    std::cout << "found at "
              << std::distance(v.begin(), it);
}
五类迭代器

  • 输入 / 输出

  • 前向

  • 双向

  • 随机访问

vector、deque 提供随机访问；list、map、set 提供双向；stack、queue 不提供迭代器。

算法要求的迭代器类别写在模板参数名里（如 RanIt、BidIt）；传入不满足的迭代器会编译失败。

范围 for 与 auto 
std::vector<Target> targets;

for (const Target& t : targets) {   // 只读，不拷贝
    std::cout << t;
}

for (Target& t : targets) {         // 可修改
    t.build();
}

for (auto& t : targets) {         // 类型由编译器推导
    t.postpone();
}
等价写法
for (auto it = targets.begin();
     it != targets.end(); ++it) {
    const Target& t = *it;
    // ...
}

范围 for 只是语法糖；底层仍然是迭代器。

选择

只读用 const auto&；需要修改用 auto&；只有在确实需要副本时才按值。

常用算法：查找、排序、统计 
#include <algorithm>
#include <numeric>

std::vector<int> v{5, 1, 4, 2, 3};

std::sort(v.begin(), v.end());          // 1 2 3 4 5
bool has3 = std::binary_search(
    v.begin(), v.end(), 3);

auto it = std::find(v.begin(), v.end(), 4);
int n = std::count_if(
    v.begin(), v.end(),
    [](int x) { return x % 2 == 0; });  // 2
int sum = std::accumulate(
    v.begin(), v.end(), 0);             // 15
算法族

  • 查找：find、find_if、binary_search

  • 排序：sort、stable_sort、partial_sort

  • 统计：count、count_if、accumulate

  • 变换：transform、copy、copy_if

  • 删除：remove_if + erase

算法接收迭代器区间 [first, last)，不接收容器本身；因此同一个算法能服务多种容器。

Lambda：匿名函数与捕获 
int threshold = 3;

auto high = [threshold](const Target& t) {
    return t.priority() >= threshold;
};

auto bump = [&threshold]() {
    ++threshold;
};

std::vector<Target> targets;
auto n = std::count_if(targets.begin(), targets.end(), high);
捕获方式

  • []：不捕获

  • [x]：按值捕获

  • [&x]：按引用捕获

  • [=] / [&]：全部按值/引用（谨慎）

  • [this]：捕获当前对象

生命周期

按引用捕获的变量必须活得比 Lambda 长；把 Lambda 存起来异步执行时，尤其要小心悬空引用。

函数对象与 std::function 
struct MatchPriority {
    int value;
    bool operator()(const Target& t) const {
        return t.priority() == value;
    }
};

std::count_if(targets.begin(), targets.end(),
              MatchPriority{3});

std::function<bool(const Target&)> pred =
    [](const Target& t) { return t.is_built(); };
三者关系

  • 函数指针：最简单，不能带状态

  • 函数对象：可带状态，可内联

  • Lambda：编译器生成的函数对象

  • std::function：类型擦除，可存放任意可调用对象

std::function 有间接调用开销；模板算法直接接受 Lambda 通常更快。
迭代器失效：容器修改后的陷阱
操作 vector list map / set
插入 可能全部失效（扩容） 不影响其他元素 不影响其他元素
删除 被删位置及之后失效 只失效被删元素 只失效被删元素
push_back 扩容时全部失效 — — 
// 错误：erase 后 it 失效
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it < 0) v.erase(it);   // 未定义行为
}
// 正确：erase 返回下一个有效迭代器
for (auto it = v.begin(); it != v.end(); ) {
    if (*it < 0) it = v.erase(it);
    else ++it;
}

// C++20：std::erase_if(v, pred);
C++20 Ranges：声明式管道 
#include <ranges>

auto result = targets
    | std::views::filter([](const Target& t) {
          return !t.is_built();
      })
    | std::views::transform([](const Target& t) {
          return t.title();
      });

for (const auto& title : result) {
    std::cout << title << '\n';
}
特点

  • 管道写法，接近“声明做什么”

  • 惰性求值：遍历时才计算

  • 不产生中间容器

  • 可与 STL 算法、范围 for 组合

与 STL 算法

Ranges 不是替代 STL，而是在其上加了一层范围抽象；底层仍是迭代器与算法。

主线案例：用 STL 组织任务 
std::vector<Target> targets;
targets.emplace_back(1, "main.o", 2);
targets.emplace_back(2, "util.o", 4);
targets.emplace_back(3, "app", 5);

std::sort(targets.begin(), targets.end(),
          [](const Target& a, const Target& b) {
              return a.priority() > b.priority();
          });

auto done = std::count_if(
    targets.begin(), targets.end(),
    [](const Target& t) { return t.is_built(); });

std::map<int, Target> by_id;
for (const Target& t : targets) by_id.emplace(t.id(), t);
容器选择

  • 任务列表：vector<Target>（遍历、排序）

  • 按编号查找：map<int, Target> 或 unordered_map

  • 按优先级调度：priority_queue<Target>

  • 去重：set<int> / unordered_set

组合

同一批数据可以用不同容器组织：vector 负责顺序，map 负责索引，priority_queue 负责调度。不要试图用一个容器解决所有问题。

课堂任务 13：任务统计
任务

给定 std::vector<Target> targets，用 STL 完成：

  1. 按优先级从高到低排序并输出
  2. 统计未完成任务数量
  3. 计算所有任务优先级的平均值
  4. 找出优先级最高的任务
  5. 删除所有已完成任务（用 erase + remove_if 或 C++20 erase_if）

要求：不使用手写 for 循环完成统计（范围 for 输出可以）。

验收标准

  • 使用 sort、count_if、accumulate、max_element

  • 比较器满足严格弱序

  • 删除后容器大小正确

  • 不越界、不使用失效迭代器

  • 输出格式清晰

提示

平均优先级 = accumulate(..., 0, ...) / size()；注意 size() 返回无符号类型。

任务 13 参考实现 
#include <algorithm>
#include <numeric>
#include <vector>

std::sort(targets.begin(), targets.end(),
          [](const Target& a, const Target& b) {
              return a.priority() > b.priority();
          });

auto undone = std::count_if(
    targets.begin(), targets.end(),
    [](const Target& t) { return !t.is_built(); });

int sum = std::accumulate(
    targets.begin(), targets.end(), 0,
    [](int acc, const Target& t) {
        return acc + t.priority();
    });
double avg = targets.empty()
    ? 0.0
    : static_cast<double>(sum) / targets.size();

auto top = std::max_element(
    targets.begin(), targets.end(),
    [](const Target& a, const Target& b) {
        return a.priority() < b.priority();
    });

targets.erase(
    std::remove_if(targets.begin(), targets.end(),
                   [](const Target& t) {
                       return t.is_built();
                   }),
    targets.end());
要点

  • sort 比较器返回 a.priority() > b.priority() 实现降序

  • accumulate 的初始值类型决定累加类型

  • max_element 返回迭代器，需检查 end()

  • remove_if 只移动元素，真正删除要靠 erase

  • C++20 可写 std::erase_if(targets, pred)

严格弱序

比较器不能写 <=；必须保证 comp(a,a) == false，否则 sort 行为未定义。

常见陷阱

容器与迭代器

  • vector 扩容后继续使用旧迭代器

  • erase 后不接收返回值

  • map[] 意外插入默认值

  • 用 size() 与 int 比较产生符号问题

  • 在范围 for 中修改容器结构

算法与 Lambda

  • 比较器不满足严格弱序

  • remove_if 后忘记 erase

  • Lambda 按引用捕获局部变量后异步使用

  • std::function 过度使用带来开销

  • 对无序容器使用需要有序的算法

原则

先选容器，再选算法；容器决定迭代器能力，算法决定对元素的要求。两者不匹配时，编译器会报错——这是好事。

小结：用容器表达结构，用算法表达操作
容器

  • vector 默认

  • list 频繁中间增删

  • map / set 有序查找

  • 适配器表达受限接口

迭代器

  • 容器与算法的桥梁

  • 五类能力

  • 修改容器后注意失效

算法

  • 区间 [first, last)

  • 谓词与 Lambda

  • 声明式表达意图

  • Ranges 进一步抽象

STL 的价值不是“少写几行循环”，而是让数据结构与算法可以独立演化，并通过迭代器安全组合。
