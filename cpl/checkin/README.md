# 课堂签到(动态码 + 附近定位)

## 使用流程

1. **课前准备(每学期一次)**:改 `config.js` 里的
   - `secret` — 换成你自己的随机串(防学生猜到码的生成规律);
   - `lat` / `lng` — 教室经纬度(百度/高德地图"拾取坐标"可得);
   - `radiusM` — 允许半径, 教学楼内 150~300 米合适。
2. **上课时**:教师电脑打开 `teacher.html` 全屏投影 —— 屏幕上是一个每 60 秒自动更换的 6 位签到码 + 学生入口二维码。
3. **学生**:手机扫二维码打开 `index.html`, 输学号 + 屏幕上当前的码, 允许浏览器定位; 在教室附近且码正确 → 显示绿色"签到成功"及凭证。
4. **收尾**:学生出示成功页/截图到课程群接龙; 教师可在教师端"凭证核验"里粘贴"学号 凭证"当场抽查真伪。

## 原理与安全边界(重要)

- 签到码 = SHA-256(`secret` + 当前分钟数) 的前 8 位十六进制取模 —— 每 60 秒换一次, 不在教室看不到屏幕上的当前码。
- "附近" = 浏览器定位与 config.js 中教室坐标的球面距离 ≤ radiusM。
- 凭证 = SHA-256(学号 + 分钟槽) 前 10 位, 教师端可离线核验(±3 分钟内有效)。
- **这是纯静态方案, 不是严格防作弊**:定位可被模拟(手机开发者选项), 码可由在场同学转发, 验证逻辑在前端可被查看。对大一课程考勤够用; 若出现代签, 升级方向是加服务端校验(如部署到校内 OJ 服务器)。
- 页面必须通过 https 访问(GitHub Pages 天然满足), 否则浏览器加密接口(crypto.subtle)不可用。

## 文件

- `config.js` — 唯一需要改的配置(密钥/教室坐标/半径)
- `index.html` — 学生签到页
- `teacher.html` — 教师端大屏码 + 二维码 + 凭证核验
