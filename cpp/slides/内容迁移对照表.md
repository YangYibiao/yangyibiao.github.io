# 内容迁移对照表

说明：

- `ppt/` 为原课程 PPT，`slides-cpl/` 为 C 语言课程参考课件，两者均**未修改**。
- “状态”含义：
  - **保留**：知识点保留，重新组织与讲授。
  - **更新**：保留知识点，但代码/表述按现代 C++ 重写。
  - **合并**：多个原 PPT 合并为一个教学单元。
  - **压缩**：保留核心思想，删减平台细节或过度展开。
  - **新增**：原 PPT 没有或只有雏形，本次补充。
- 新课件按 17 周 × 2 学时组织，每份课件对应一次课。

## 三、新增内容

原 PPT 未系统展开、本次新增的内容：

1. **移动语义与五法则**（第 5 周）：左值/右值、移动构造/赋值、`std::move`、`noexcept`、RVO。
2. **RAII 与所有权**（第 3、5、14 周）：资源生命周期绑定对象、异常安全、所有权模型。
3. **智能指针体系**（第 14 周）：`unique_ptr`、`shared_ptr`、`weak_ptr`、循环引用、定制删除器。
4. **异常安全**（第 11 周）：基本/强/不抛保证、`noexcept`、RAII 与栈展开。
5. **现代 C++ 特性**：`auto`、范围 `for`、Lambda、`override/final`、结构化绑定、`optional`、Ranges、Concepts、`<=>`。
6. **并发同步**（第 15 周）：条件变量、生产者-消费者、atomic、`async/future`、线程池、死锁避免。
7. **内存安全工具**（第 14 周）：ASan/UBSan/TSan 的使用方法与读报告。
8. **工程实践**（第 17 周）：模块划分、测试策略、Git、AI 使用边界、评分与答辩。
9. **主线案例 MiniBuild**：贯穿 17 周的连续演进，替代零散案例。
10. **现代 C++ 工具速览**（第 17 周）：结构化绑定、`optional`、`filesystem`、`string_view`。

## 四、压缩或降为选讲的内容

| 原内容 | 处理 | 原因 |
| :-- | :-- | :-- |
| Win32 API / MFC 消息循环细节 | 压缩为事件驱动通用模型 + Qt/Web 类比 | 平台细节过时、与课程主线关系弱；保留“事件循环/回调”本质 |
| `new/delete` 重载实现对象内存池 | 保留“可重载”的事实与风险，删去完整内存池代码 | 现代 C++ 更推荐容器/智能指针/分配器；完整实现超出 2 学时 |
| STL 五类迭代器的完整能力表 | 保留类别与典型容器，弱化形式化定义 | 大一学生先用起来，细节可在后续课程展开 |
| fat pointer / shadow memory / trie 元数据 | 保留“动态边界检查”的思想与开销结论 | 研究方向细节不适合作为本科入门重点 |
| 逻辑式程序设计完整语法 | 保留 Prolog 事实/规则示例与思想 | 只需理解“声明式”的另一分支，不要求掌握 Prolog |
| `printf/scanf` 格式串细节 | 仅作为 C 风格对照 | 先修课程已学；本课程重点是 iostream |
| 事件驱动的具体 Windows 消息常量 | 保留少量典型消息作为例子 | 避免记忆平台常量 |
