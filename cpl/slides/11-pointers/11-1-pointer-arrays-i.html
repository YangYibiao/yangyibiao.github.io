指针算术: 三种运算

指针指向数组元素后, 可以做指针算术:

int a[10], *p;
p = &a[0];   /* p 指向 a[0] */
*p = 5;      /* a[0] = 5 */

C 的指针算术只有三种形式:

  • 指针 + 整数: p + j

  • 指针 - 整数: p - j

  • 两个指针相减: p - q

p + q、p * 2 等写法不合法. 比较指针（<、== 等）不属于算术运算, 后面单独讲.


p = &a[0]

*p = 5

指针算术: 地址值怎么变

公式:

(p + j) 的值 = p 的值 + j × sizeof(*p)
(p - j) 的值 = p 的值 − j × sizeof(*p)

依据: C 的指针算术以所指对象为单位, 编译器按 sizeof(*p) 缩放.

不同指针类型的 sizeof(*p) 不同: char * 为 1、int * 为 4、double * 为 8 (常见平台), 所以 p + 1 分别增加 1/4/8 字节.

注意: p 的值是 p 中保存的地址, 不是指针变量 p 自身的地址 &p.

结果必须仍指向同一数组(或最后一个元素之后); 移出数组范围是未定义行为.

+ 整数（假设 int *p）
表达式 值（地址） 指向
p0x1008a[2]
p + 30x1014a[5]
− 整数（假设 int *p）
表达式 值（地址） 指向
p0x1020a[8]
p - 30x1014a[5]

两个指针相减是同一原理的逆运算: (p - q) 的值 = (p 的值 − q 的值) / sizeof(*p), 结果是元素个数——下一页.

两个指针相减

当一个指针从另一个指针中减去时, 结果是指针之间的距离(数组元素的个数).

p 指向 a[i]、q 指向 a[j], 则 \(p - q = i - j\). 示例:

p = &a[5];
q = &a[1];
依据: 指针相减和指针加减整数是同一个原理: 地址值之差要除以 sizeof(*p), 得到元素个数.
(p - q) 的值 = (p 的值 − q 的值) / sizeof(*p).

例如 int *: p 的值 0x1020、q 的值 0x1010, 则 (0x1020 - 0x1010) / 4 = 4 个元素.

  • 只有两个指针指向同一个数组时, 相减才有意义

  • 对不指向数组元素的指针做算术运算会导致未定义行为

i = p - q; /* i is  4 */
i = q - p; /* i is -4 */
比较指针

关系运算符(<, <=, >, >=)和判等运算符(==, !=)进行指针比较.

使用关系运算符仅对指向同一数组元素的指针有意义. 比较的结果取决于数组中两个元素的相对位置.

p = &a[5];
q = &a[1];
p <= q; // expression value: 0
p >= q; // expression value: 1
使用指针进行数组处理 
#define N 10
int a[N] = {11, 34, 82, 7, 64, 98, 47, 18, 79, 20};
int sum = 0, *p;
…
for (p = &a[0]; p < &a[N]; p++)
    sum += *p;

  • 在第一次迭代结束时：p 指向 a[1]，sum 为 11（已加上 a[0]）

  • 在第二次迭代结束时：p 指向 a[2]，sum 为 45（又加上 a[1]）

  • 在第三次迭代结束时：p 指向 a[3]，sum 为 127（又加上 a[2]）

for 语句中的条件 p < &a[N] 值得特别提及。将地址运算符应用于 a[N] 是合法的，即使此元素不存在。

课堂编码

任务：用指针遍历数组，实现两个函数。

  • int find_sum(int *a, int n)：返回数组所有元素之和。

  • int find_max(int *a, int n)：返回数组元素的最大值。

要求：只用指针 *p 访问元素，不使用下标 a[i]；循环变量在 for 中自声明。

样例输入：34 82 49 102 7 94 23 11 50 31

样例输出：sum = 483、max = 102

完成标准:
· 只用 *p 遍历, 不使用下标 a[i]
· 输出 sum = 483、max = 102
· 循环变量在 for 中自声明

提示：求和让 p 从 a 走到 a + n，每次把 *p 累加；求最大值先把 max 初始化为 *a，再从 a + 1 开始逐个比较。

先想参数：函数需要数组首元素地址 a 和元素个数 n——指针本身不知道数组有多长。

⚡ 在 VS Code 中打开 skeleton.c (框架已备好)
课堂编码 · 参考实现
参考实现 · find-sum-max.c
#include <stdio.h>

#define N 10

int find_sum(int *a, int n)
{
    int sum = 0;
    for (int *p = a; p < a + n; p++)
        sum += *p;
    return sum;
}

int find_max(int *a, int n)
{
    int max = *a;
    for (int *p = a + 1; p < a + n; p++)
        if (*p > max)
            max = *p;
    return max;
}

int main(void)
{
    int b[N] = {34, 82, 49, 102, 7, 94, 23, 11, 50, 31};

    printf("sum = %d\n", find_sum(b, N));   /* 483 */
    printf("max = %d\n", find_max(b, N));   /* 102 */
    return 0;
}
⚡ 在 VS Code 中打开 find-sum-max.c
运行结果
sum = 483
max = 102

  • 两个函数都用指针遍历: for (int *p = a; p < a + n; p++)

  • find_sum 累加 *p; find_max 先取 *a, 再从 a + 1 开始比较

两个循环都用 p < a + n 作条件, 指针不会走到数组之外; 调用时数组名 b 自动作为 &b[0] 传入.

结合 * 和 ++ 运算符 
p = &a[0];
while (p < &a[N])
    sum += *p++;
表达式 意义
*p++或*(p++) 表达式的值是*p在递增之前, 之后自增p
(*p)++ 表达式的值为*p在递增之前, 稍后增加*p
*++p或*(++p) 先递增p, 表达式的值为*p
++*p或++(*p) 先递增*p, 表达式的值为*p

C程序员经常结合使用*(间接寻址)和++运算符.

修改数组元素后前进到下一个元素的语句: a[i++] = j;

对应的指针版本: *p++ = j;

因为后缀++的优先级高于*, 编译器将其视为 *(p++) = j;

*和++的可能组合见左栏表格.

  • *(p++) 指针自增(指向下一个对象)

  • (*p)++ 指向的对象自增(p本身不变)

\*和++最常见的组合是*p++, 在循环中很常用. 前面「使用指针进行数组处理」的求和 for 循环可以改写成左栏的 while 版.

结合 * 和 ++: 现场演示
完整代码 · pointer-inc-demo.c
#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;
    int v;

    v = *p++;
    printf("*p++   = %d, p -> a[%d]\n", v, (int)(p - a));
    printf("*p     = %d\n", *p);

    p = a;
    v = (*p)++;
    printf("(*p)++ = %d, a[0] = %d, p -> a[%d]\n", v, a[0], (int)(p - a));
    printf("a[0]   = %d\n", a[0]);

    p = a;
    v = *++p;
    printf("*++p   = %d, p -> a[%d]\n", v, (int)(p - a));

    p = a;
    v = ++*p;
    printf("++*p   = %d, a[0] = %d\n", v, a[0]);
    return 0;
}
⚡ 在 VS Code 中打开 pointer-inc-demo.c (现场演示)
运行结果
*p++   = 10, p -> a[1]
*p     = 20
(*p)++ = 10, a[0] = 11, p -> a[0]
a[0]   = 11
*++p   = 20, p -> a[1]
++*p   = 12, a[0] = 12

  • *p++: 先取值, 再后移

  • (*p)++: 值加 1, p 不动

  • *++p: 先后移, 再取值

  • ++*p: 所指值先加 1

结合 * 和 ++: 栈的应用
索引版
#define N 100
int contents[N];
int top = 0;

void push(int i) { contents[top++] = i; }
int pop(void)   { return contents[--top]; }
指针版
int *top_ptr = contents;

void push(int i) { *top_ptr++ = i; }
int pop(void)   { return *--top_ptr; }

  • top / top_ptr 都指向下一个空位.

  • push: 先存入, 再后移——contents[top++] = i 对应 *top_ptr++ = i.

  • pop: 先前移, 再读取——contents[--top] 对应 *--top_ptr.

  • *p++ 等价于 *(p++); *--p 等价于 *(--p).

  • 这里假设栈不溢出/不下溢; 工程代码要加边界检查 (下一页演示).

栈的现场演示: stack-demo.c
完整代码 · stack-demo.c
#include <stdio.h>

#define N 5

int contents[N];
int *top_ptr = contents;

void push(int i)
{
    if (top_ptr == contents + N) {
        printf("栈满\n");
        return;
    }
    *top_ptr++ = i;
}

int pop(void)
{
    if (top_ptr == contents) {
        printf("栈空\n");
        return -1;
    }
    return *--top_ptr;
}

int main(void)
{
    push(7);
    push(8);
    push(9);
    printf("pop = %d\n", pop());
    printf("pop = %d\n", pop());
    push(10);
    printf("pop = %d\n", pop());
    printf("pop = %d\n", pop());
    return 0;
}
⚡ 在 VS Code 中打开 stack-demo.c (现场演示)
运行结果
pop = 9
pop = 8
pop = 10
pop = 7

  • 先 push 7、8、9; 两次 pop 得到 9、8.

  • 再 push 10; 两次 pop 得到 10、7.

  • *top_ptr++ 先写入当前位置, 再自增; *--top_ptr 先自减, 再读取.

边界检查: 栈满/栈空时直接返回, 避免越界.
