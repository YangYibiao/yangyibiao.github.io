课程简介

本课程从《程序设计基础》出发，逐步建立面向对象思维，理解现代 C++ 的语言机制与工程方法。 课程不追求罗列全部语法，而是围绕抽象与边界、生命周期与资源、复用与并发三条主线展开。

抽象与边界

类、接口、继承、多态、模块。让每个类守护自己的不变量，让高层代码依赖稳定接口。

生命周期与资源

构造/析构、拷贝/移动、RAII、智能指针、异常安全。让“谁负责释放”成为类型系统的一部分。

复用与并发

模板、STL、Lambda、线程与同步、声明式与事件驱动。用合适的抽象控制复杂度。

课程以 MiniBuild 构建系统 为主线案例：从 C 结构体到类，从继承到多态，从裸指针到智能指针， 从单线程到线程池，最终形成一个可运行、可测试、可讲解的课程项目。
